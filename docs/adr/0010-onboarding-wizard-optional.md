# 初始化流程采用"可选向导 + 自由访问"混合模式

首次登录推荐进入 6-8 步初始化向导（学校信息 → 作息表 → 年级班级 → 教师 → 教室 → 课程 → 授课任务 → 约束规则），**可跳过**。每一步支持 Excel 批量导入或逐条手动录入，支持保存进度下次继续。向导完成后进入主界面，之后所有功能自由访问，无强制流程。

## 为什么

- 强制向导（B 方案）对老用户不友好——第二个学期开学时不需要重走全流程
- 完全自由（A 方案）让新用户不知道从何下手（先建班级还是先建课程？）
- 混合模式让首次有引导、后续自由

## Consequences

- 向导本身是一个独立的"任务进度"对象存库，不依赖前端 state，可跨会话恢复
- 每个数据实体（年级/班级/教师/教室/课程/授课任务）的 CRUD 界面与 Excel 导入必须独立可用，不能在向导之外被锁死
- 主界面在数据不完整时给出"还差什么"的引导提示，但不阻止访问
