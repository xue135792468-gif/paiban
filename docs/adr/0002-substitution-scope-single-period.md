# 第一版调代课只支持单节课变更，不支持跨周或连续调整

课表发布后的临时变更（调代课）限定为：单次操作只针对一个具体课节（某天某节），允许换老师、换教室、换时间（一周内另一个空课节）三者之一或组合。明确不支持跨周调整、不支持"老师请假一周"这类连续调代。

## 为什么

- **"调代课"场景的真实痛点是临时性**：80% 以上的场景是"张老师明天下午请假一节"，跨周调课低频且管理流程复杂（涉及代课费结算、家长通知范围扩大），一期做进来回报率低。
- **冲突检测的复杂度**：单节课调代的冲突检测是局部的（只看那个课节）；连续调代需要在整周范围内做级联校验，会拖慢一期交付。
- **钉钉通知价值最大**：单节课调代的通知链路最短（代课老师 + 受影响班级班主任 + 任课老师），最容易做出"钉钉集成亮点"。

## Consequences

- 如果老师请假超过一天，需要逐天发起调代申请。可接受，二期再加批量。
- 数据结构（Substitution 记录）必须为未来"关联多个课节"预留扩展位（比如 substitution_group_id），避免二期迁移数据。
