# 管理员调度以具体授课实例为单位，课前再次调整保留修订历史

Status: proposed（用户已确认产品方向，完整规格待确认）

管理员调代工作台按具体日期的一次授课管理临时安排。已发布基线继续只读；调课保留同班置换环、确定性搜索和独立校验器，代课只换教师。新增“授课实例”身份，使跨日期移动、改代课人及再次移动始终指向同一次授课，不波及以后各周。

## 已确认的产品决定

- 获授权的管理员可代任意教师发起，也可亲自批准。申请可以进入待审批队列，或在预览后由管理员确认生效；操作者使用自己的账号，不冒充被调整教师。
- 调整前后对照以本次操作前的最新安排为左侧，以所选方案应用后的安排为右侧，完整列出本次变化。
- 授课尚未开始且重新校验通过时允许再次调整，旧安排和操作历史保留；已经开始或结束的授课不允许改写。
- 调代只作用于列出的实际日期。窗口内可跨周，未涉及的以后各周沿用基线。

## 取舍与后果

现有读取逻辑按基线条目取“查询日前最后一笔调代”，会把一次代课延续到以后各周，也不能准确区分跨周的两次同槽授课。为满足已确认的一次性语义，读模型、求解快照、导出和统计必须共同转向按授课实例解释生效修订。仅放开重复提交限制无法完成本功能。

历史生效事件和方案移动用于恢复原始授课日期、实际来源和目标日期；不能覆盖旧记录或按最后写入顺序猜测历史。无法唯一恢复的历史数据必须在上线前报告并处理，迁移失败时保留原数据。迁移版本在实施时核对所有分支后分配。

新修订从当前安排计算增量，整单校验并原子生效；统计使用最终有效安排与基线的差额，中间安排只进入历史。多人方案不允许部分生效或为了重调某一课而回滚其他已发生授课。

本决定细化 ADR-0008 的叠加层为按日期解释，替代其“截至查询日最后一笔覆盖整个周模板”的读取语义；保留基线只读、叠加事件和可追溯性。它扩展 ADR-0025 的授课身份与再次调整能力，保留同班环、排序、30 分钟方案有效期以及独立校验器的边界。

完整交互、截止规则与兼容要求见管理员调代工作台规格。确认规格前不执行功能实现或数据库变更。
