# 部署形态：私有化优先，一套代码支持本地 / 学校内网 / 云服务器三种运行位置

系统打包为两种交付形态：

- **Docker Compose 包**：`docker-compose.yml` 一键起 PostgreSQL + 应用 + Nginx，推荐给有 IT 能力的学校或云服务器部署
- **裸机 Jar 包**：`paiban.jar` + `start.bat` / `start.sh`，学校自装 JDK 21 与 PostgreSQL

代码本身不感知运行位置（本地笔记本 / 学校内网 / 公有云一视同仁），通过配置文件区分环境。

## 为什么

- **数据敏感**：中学涉及学生与教师信息，私有化部署更容易被学校接受
- **钉钉 Stream 模式**：通过 WebSocket 长连接接收钉钉事件，无需公网回调域名，私有化部署零障碍
- **架构上不阻碍 SaaS**：一期不做多租户，但代码不预设"必须单租户"，二期加 `tenant_id` 字段即可演进

## Consequences

- 钉钉集成的"事件回调"一律走 Stream 模式，不依赖 Webhook
- 外部 URL（钉钉免登回调、课表分享链接）必须从配置读取，不写死
- 文件存储（Excel 导入临时文件、PDF 导出）走本地文件系统或 MinIO，不依赖云对象存储
