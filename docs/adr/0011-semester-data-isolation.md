# 学期数据组织：全局资产 + 学期隔离业务数据

**全局数据（跨学期共享）**：教师、教室、课程、组织架构。

**学期隔离数据**：行政班、教学班、授课任务（Assignment）、课表基线、调代单、约束配置。每条记录都带 `semester_id` 外键。

**新学期开学**：提供"从上学期复制"功能，复制班级结构、授课任务、约束配置作为起点，教务在副本上调整。

**升学自动化**：一期不做。新学期教务通过 Excel 导入新班级即可。升学涉及毕业班归档、新生入学、留级、转学等边界场景，一期做了会变形，二期视需要再做"升学向导"。

## 为什么

- 教师/教室/课程是"学校资产"，跨学期基本不变，全局维护避免重复录入
- 班级（高一 1 班 ≠ 高二 1 班）、授课任务、课表、调代都严格按学期隔离，避免历史数据污染当前学期
- 学期隔离让"回看历史学期的课表与调代"成为天然的副产品

## Consequences

- 所有学期隔离的实体都必须带 `semester_id` 索引，查询时强制按学期过滤
- 当前学期是系统级设置，全局只有一个"当前学期"，避免教务在多学期之间混淆操作
- "从上学期复制"是一等公民功能，不是导入导出的变通方案
