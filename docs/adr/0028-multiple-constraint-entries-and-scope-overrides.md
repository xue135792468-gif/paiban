# 约束按类型控制、多条对象条件与具体对象覆盖

日期：2026-10-25
状态：Accepted（产品语义已确认，原型与实现待后续）

## 背景

每学期每类型仅一行配置会让第二个对象覆盖第一个。简单改成列表会产生重复惩罚、偏好“且/或”歧义和不同评估入口不一致。逐条独立软硬权重又会显著增加页面和求解复杂度。

## 决定

- 同类条目共用启用、软硬和权重；各条只承载对象与条件。页面采用分组折叠卡片，先以原型确认。
- 禁排取并集；同一教师的多个偏好时段是可选集合。
- 同一课程互斥教室要求、重复对象阈值明确拒绝，不以最后一条覆盖。
- 五类阈值支持全局默认＋自然适用对象例外，具体对象替代全局；不为不适用的对象类型开放万能作用域。
- 原有单条配置与模板保留含义；求解、草稿、发布、调代独立检查及 CLI 使用一致条目集合与匹配。
- 用户已确认上述控制层级、覆盖与组合语义，并认可六张端到端票据的划分。

## 后果

后续需迁移唯一限制、保存身份和读取契约，覆盖完整 24 类目录及模板。原型获确认是实施门槛；本 ADR 不表示代码已上线，也不包含自然语言生成。
