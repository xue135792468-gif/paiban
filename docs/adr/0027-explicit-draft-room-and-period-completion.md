# 显式补齐缺教室与缺课节，保持导入和制度数据的边界

日期：2026-10-25
状态：Accepted（需求决策已确认，代码尚未实现）

## 背景

ADR-0026 将自动创建教室及学期作息排除在工作簿导入之外。真实文件缺教室和节次时，用户又需要可执行的补齐入口。隐式猜测会污染全局主数据或固化学校制度；完全手工逐节修正成本过高。

## 决定

- 导入读取、解析与普通确认提交仍不隐式建教室或作息。
- 草稿可以提供显式确认动作，为行政班创建固定普通教室并只补缺失分配；专用要求及冲突不能强制绕过。
- 缺失节次先展示拟新增时间，用户确认后只追加。推算没有可靠依据或跨越不确定作息边界时转人工。
- 所有补齐保留已有数据与引用；已发布学期继续只读。补齐失败不能制造部分主数据写入。
- 用户已在本轮分别确认“每班固定普通教室”和“先预览再确认、不可靠项转人工”。

## 后果

这是 ADR-0026 范围的定向扩展，不是让 AI 决定学校作息或让导入自动创建教室。执行验收见六项修复补充规格。两动作需要服务层权限、幂等和事务保护。
