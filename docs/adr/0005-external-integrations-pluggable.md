# 所有外部集成（钉钉/飞书/AI）都是可插拔适配器，本地数据为唯一事实源

教职工、学生、班级、教室、课程等基础数据全部以本地数据库为唯一事实源，支持手动录入与 Excel 导入。钉钉/飞书同步是可选的"数据源适配器"：启用时可从对应平台导入教职工、同步入离职事件、用于登录与通知；禁用或移除后系统功能完整。

## 为什么

- **避免厂商锁定**：学校可能三年后从钉钉迁到飞书或企业微信。如果业务数据以钉钉为事实源，迁移等于重做系统。
- **离线可用**：学校内网部署时钉钉可能完全不可达，核心业务必须能跑。
- **统一架构姿态**：与 ADR-0003（AI 特性可选）一致——任何"外部依赖"都是可拔插的增强，不是地基。

## 架构形态

- 定义抽象接口：`OrgDataProvider`（组织数据导入）、`AuthProvider`（身份认证）、`NotificationChannel`（消息通知）
- 钉钉是上述接口的第一组实现，飞书二期接入
- 本地实现（`LocalOrgDataProvider` / `LocalAuthProvider` / `LocalNotificationChannel`）永远可用，是默认 fallback
- 业务代码只依赖接口，不知道当前用的是哪家

## Consequences

- 教职工表的主键是本地 ID，钉钉 userId 只是一个外部映射字段
- 即便钉钉同步开启，也允许本地修改教师信息（下次同步时以钉钉为准或保留本地？→ 默认"钉钉为准"但保留本地覆盖开关）
- Excel 导入是一等公民，不是"没有钉钉时的降级方案"
