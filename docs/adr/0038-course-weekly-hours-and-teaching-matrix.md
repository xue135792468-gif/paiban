# 课程默认周课时、任课表方阵与班主任自动分组

Status: accepted（2026-11-26，三轮访谈全部确认，规格已发布至 `.scratch/course-weekly-hours-and-teaching-matrix/spec.md`）

课程新增的「周课时数」（1–20 或空）定位为课程目录级的默认每周节数，采用创建时复制语义：新建授课任务或导入任课表时自动预填每周节数，后续修改课程默认值不回溯改写已有授课任务，也暂不引入独立的「课程 × 年级」周课时表；个别年级或班级的课时差异可在任课表导入预演页或任课表单元格内直接覆盖。

「任课表」不另建独立数据表，而是以「行政班 × 课程」二维方阵直接读写现有授课任务，同时展示并允许在导入时合并更新行政班的学生人数与班主任，确保排课求解器无需任何改动即可直接按任课表安排的教师排课。任课表 Excel 导入采用两阶段暂存导入（只读预演 → 单事务原子提交）：上下文显式绑定目标学期与年级，允许在预览确认后自动补建缺失的行政班、教师与课程，重导时按复合键幂等更新表内出现的学科、不删除未列出的学科、空格跳过、同名教师阻断不猜测。任课表格子内的删除复用现有软删除、影响确认与 7 天回收站恢复机制，并提供即时撤销入口。

「班主任分组」复用排课规则现有的教师规则分组及 `auto_filled` 自动维护机制，由基础数据域通过领域事件驱动同步：始终依据当前学期的行政班班主任自动维护全校总组「班主任」及各年级「{年级名}班主任」分组，兼顾全校统一与分年级排课规则需求；任一自动分组一旦被人工编辑即清除自动标记，转为手工维护，不再被后续同步覆盖。

## Considered Options

- **新建独立的「课程 × 年级」周课时表或独立任课表**：拒绝。会引入双份数据同步与额外维护成本；当前中学场景以「课程默认值 + 预演/格子微调」即可覆盖极少数跨年级差异。
- **任课表导入时仅忽略人数/班主任，或禁止自动补建缺失实体**：拒绝。学校常在新学期开局直接用任课表 Excel 作为首要数据源，忽略或强迫先手工逐页建档会割裂开局流程。
- **班主任分组在导入时弹出单选（全校 vs 分年级）**：拒绝。学校实际可能同时存在全校班主任例会与分年级班主任教研两种规则需求，双轨自动维护零配置且随时可手工接管。
