# 安装指南截图清单

`docs/installation-guide.md` 引用以下截图。当前仓库只保留占位说明，**不要提交伪造或合成的界面截图**；请在实际安装过程中按真实界面截取后再放入本目录。

统一要求：

- 格式：PNG
- 宽度：1440 px（高度按内容裁切，建议 900～1200 px）
- 界面语言：简体中文
- 需要强调的位置用红框或箭头标出；截图里的账号、密码、学校名称等个人信息请打码
- 文件名必须与下表完全一致（区分大小写）

| 文件名 | 应展示的内容 | 建议尺寸 |
| --- | --- | --- |
| `step1-docker-install.png` | Docker Desktop 官方下载页，突出 Windows / Mac 的下载按钮；或安装完成后鲸鱼图标变绿的 Docker Desktop 主界面 | 1440 × 900 |
| `step2-download.png` | GitHub 仓库页面，突出绿色的 **Code** 按钮和 **Download ZIP** 菜单项；或解压后能看到 `start.bat` 的文件夹窗口 | 1440 × 900 |
| `step3-start.png` | 双击 `start.bat` 后弹出的黑色窗口（Windows），或终端里执行 `./start.sh` 的画面，能看到 `[1/5]`～`[4/5]` 的进度 | 1440 × 900 |
| `step4-wait.png` | 启动成功的画面，必须完整显示 `[完成] 排课系统已启动`、前端地址、后端地址和默认账号四行 | 1440 × 900 |
| `step5-browser.png` | 浏览器地址栏为 `http://localhost:5173` 的登录页，能看到用户名、密码输入框和登录按钮 | 1440 × 1000 |
| `step6-onboarding.png` | 首次登录后的“初始化向导”页面，能看到步骤条和“学校信息”第一步 | 1440 × 1000 |

截图更新后，请确认 `docs/installation-guide.md` 中的引用路径仍为 `./images/<文件名>`。
