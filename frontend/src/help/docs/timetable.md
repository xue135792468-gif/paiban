# 课表查看

菜单：**课表 → 课表查看**（`/timetable`）

课表查看是只读页面，用于按不同对象查看已发布的课表，并导出给教师或张贴。

## 视角切换

<a id="views"></a>

页面顶部有两组切换：

1. **查看对象**：行政班 / 教师 / 教室 / 全校。选择后在右侧下拉中选中具体对象。
   - 普通教师只看到「教师」视角（以及自己担任班主任的班级）。
   - 「教室」与「全校」视角需要查看全部课表的权限。
2. **版本**：最新 / 原始。
   - **最新**：包含已生效的调代，是当前实际执行的课表。
   - **原始**：发布时的基线课表，不含调代。

右侧的日期选择器用于查看某一天的课表；不选日期时显示整周。

## 调代标记

<a id="substitution-mark"></a>

课表中被调代过的课节会显示「代」标签，单元格内容为「课程 · 代课教师」。将鼠标悬停在课节上可以看到：

- 原教师
- 代课教师
- 调代原因与备注

在「原始」视角下不会出现「代」标记，因为原始视角展示的是发布时的基线。

## 导出

<a id="export"></a>

点击右上角【导出】按钮，选择格式：

- **导出 Excel**：适合继续加工或做统计。
- **导出 PDF**：适合打印张贴，页眉会带上设置里的学校名称与校徽。

导出前需要先选中具体的班级、教师或教室。未选择时页面会提示「请先选择要导出的对象」。导出内容跟随当前视角与版本，因此导出「最新」即包含调代后的结果。
