# 排课

排课分为四步：确认授课任务 → 配置排课规则（可选）→ 提交自动排课 → 在草稿上微调并发布。本页按这个顺序说明。

## 授课任务

<a id="assignments"></a>

菜单：**数据管理 → 授课任务**（`/data/assignments`）

授课任务的定义是：**行政班 + 课程 + 每周节数 + 任课教师**。

1. 点击【新增授课任务】。
2. 选择行政班与课程。
3. 填写「每周节数」——这是该班每周要上几节这门课，直接决定排课总量。
4. 选择任课教师。

同一行政班所有课程的每周节数之和，不应超过作息表提供的总课节数，否则排课一定失败。录入完成后可在此页核对总数。

## 排课规则

<a id="constraints"></a>

菜单：**排课规则**（`/rules`）

规则不是必填项。不写规则也能排课，系统只保证两条基础冲突不出现：同一教师同一时间不撞课、同一行政班同一时间不撞课。所有规则都按同样三件事判断：对谁、哪些课、什么时候。

用三种句型拼规则：

- **时段型**（在什么时候不排）：例如「王老师周五下午不排课」「周一下午第三节固定为班会」。
- **数量型**（每天最多几节）：例如「八年级数学每天最多 1 节」。
- **形态型**（连堂、分散、不空堂）：例如「八年级语文连堂 2 节」「某老师连续上课不超过 3 节」。

页面上可拼的规则共 17 类，加上两条系统基础冲突合计 19 类。规则可以随时开关；关掉一条不会删掉它的内容。

按类型逐条配置的高级入口仍在 **排课规则 → 按类型**（`/rules/advanced`），用于查看每条规则的作用范围与参数。

## 每周固定不上课

在规则页选择「每周不上课」（时段型），明确选「全校」或「指定班级」。指定班级可多选，不能空选；全校规则也适用于本学期以后新增的班级。

这些位置每周固定留空，原来的周课时仍要排到其他位置。多条留空规则取并集，重叠只算一次；暂停一条后，其他规则覆盖的位置仍不上课。容量不足会列出班级、需要课时、可用位置和差额：可以保存规则，但开始排课前必须先解决不足。

草稿班级视图用灰色「不上课」标记留空位置，不能拖入课程。已有课程占位时会保留并提示冲突，可以移出去，不会自动删课。已经发布的原始课表保持不变，之后调课也必须遵守新规则。本功能按周重复，不用于某个具体日期的临时停课。

## 提交排课

<a id="run"></a>

菜单：**课表工作台**（`/workbench`）

1. 在顶部选择学期。
2. 在「发起排课任务」中填写「草稿名称」（例如：方案 A），选择要排的年级与「最大求解时长(秒)」。
3. 点击【开始排课】。

求解器同一时刻只运行一个任务，如果已有任务在跑，需要等待或先【取消任务】。运行中会显示进度、当前得分与硬冲突数。任务完成后点击【打开草稿】进入草稿编辑器。

若页面顶部提示「排课前请先录入授课任务并配置作息表」，说明输入还不完整，先补齐对应数据。

也可以不从零排课：在课表工作台用【导入课表】把现成工作簿变成草稿，或创建空白草稿手动填。已有草稿想用当前安排继续优化时，打开该草稿使用【继续优化】，会另建一份新草稿并保留原稿与锁定。

## 草稿微调

<a id="draft"></a>

页面：课表草稿（`/workbench/drafts/:id`）

- 拖拽课节到其他时段即可调整。拖动时绿色表示可放置，红色表示有冲突；点击红格可以查看冲突原因。
- 顶部统计显示「硬冲突」数量，硬冲突不为 0 时无法发布。
- 锁定某节课（或在教师视图里换课）不会限制你手动拖动或删除草稿。
- 可以【重命名】草稿，不需要的方案直接【删除】，删除后 7 天内可以在「最近删除」里撤销。

## 发布与撤回

<a id="publish"></a>

确认草稿无误后点击【发布课表】。发布后：

- 该草稿成为本学期的正式课表基线。
- 基线只读，单节课的变更走调代流程，而不是继续改草稿。
- 课表查看页选择「原始」视角看到的就是这份基线。

发布后仍可【撤回为草稿】重新调整：撤回只撤掉已发布的基线，调代历史保留；撤回前页面会列出未来日期里会失效的调代条数，确认后再撤。

发布失败时页面会提示原因（通常是仍有硬冲突）。解决冲突后再次发布即可。
