# 基础数据

基础数据是整个排课系统的输入：没有年级、班级、教师、教室和课程，就无法录入授课任务，也无法开始排课。本页按「先有什么、后有什么」的顺序介绍各页面。

> 提示：所有基础数据都归属于当前学期。切换学期后，看到的是另一套数据。

## 年级

<a id="grades"></a>

菜单：**教务 → 年级**（`/admin/grades`）

1. 在顶部选择学期。
2. 点击【新增年级】，填写「年级名称」（例如：高一、初一）与「排序序号」，确定。
3. 年级用于给行政班分组，排序序号决定课表与列表里的显示顺序。

如果年级列表为空，页面会提示先创建年级；也可以使用【导入】按钮下载模板后批量录入。

→ [打开年级管理](/admin/grades)

## 行政班

<a id="classes"></a>

菜单：**教务 → 行政班**（`/admin/classes`）

1. 点击【新增行政班】。
2. 依次选择「所属年级」，填写「行政班名称」（例如：1班、高一(1)班）与「学生人数」。
3. 「班主任」为可选项，选定后班主任登录即可查看本班课表、提交调代申请。

行政班是排课的基本单位：一个行政班在一节课上只能有一门课程。

→ [创建班级](/admin/classes)

## 教师

<a id="teachers"></a>

菜单：**教务 → 教师**（`/admin/teachers`）

- 必填项是「姓名」，建议同时填写「工号」与「任教学科」。
- 教师记录会同时用于授课任务的任课教师、调代的申请人与代课人。
- 支持【导入】批量录入，也可【导出】当前名单做备份。

教师本身不能登录系统；需要在 **系统 → 用户管理**（`/admin/users`）里创建账号并关联教师，教师才能提交调代。

## 教室

<a id="rooms"></a>

菜单：**教务 → 教室**（`/admin/rooms`）

- 填写「教室名称」「所在楼栋」「教室类型」与「容纳人数」。
- 教室类型会与课程的「教室要求」匹配，例如实验室课程只会排进对应类型的教室。
- 普通教室、实验室、操场等都在这里统一维护。

## 课程

<a id="courses"></a>

菜单：**教务 → 课程**（`/admin/courses`）

| 字段 | 作用 |
|---|---|
| 课程名称 | 课表上显示的名称 |
| 所属学科 | 用于统计与筛选 |
| 教室要求 | 需要特定教室类型时选择 |
| 连堂设置 | 「允许连堂」表示该课程可以连续两节安排 |
| 场地设置 | 需要室外场地时打开 |
| 课表颜色 | 课表单元格的底色 |

课程是全校共用的目录，不按学期隔离；每学期的差异通过授课任务体现。

## 批量导入

<a id="import"></a>

教师、教室、年级、行政班等页面右上角都有【导入】按钮，流程一致：

1. 点击【导入】，下载 Excel 模板。
2. 按模板填写数据，注意不要改动表头。
3. 上传文件，系统会校验并在导入结果里列出成功与失败的行。
4. 失败行按提示修正后重新导入即可，已成功的行不会重复创建。

如果手上只有零散名单（聊天记录、照片），可以改用 **教务 → AI 数据导入**（`/admin/ai-import`）：支持上传 Excel / CSV、粘贴文本、上传图片三种方式，AI 解析后先预览，确认无误再写入。
