# 基础数据

基础数据是整个排课系统的输入：没有年级、班级、教师和课程，就无法录入授课任务，也无法开始排课。本页按「先有什么、后有什么」的顺序介绍各页面。这些页面都在 **数据管理** 下。

> 提示：年级、行政班、授课任务都归属于当前学期。切换学期后，看到的是另一套数据。

## 年级

<a id="grades"></a>

菜单：**数据管理 → 年级**（`/data/grades`）

1. 在顶部选择学期。
2. 点击【新增年级】，填写「年级名称」（例如：初一、初二）与「排序序号」，确定。
3. 年级用于给行政班分组，排序序号决定课表与列表里的显示顺序。

如果年级列表为空，页面会提示先创建年级；也可以使用【导入】按钮下载模板后批量录入。

→ [打开年级管理](/data/grades)

## 行政班

<a id="classes"></a>

菜单：**数据管理 → 行政班**（`/data/classes`）

1. 点击【新增行政班】。
2. 依次选择「所属年级」，填写「行政班名称」（例如：1班、初一(1)班）与「学生人数」。
3. 「班主任」为可选项，选定后班主任登录即可查看本班课表、提交调代申请。

行政班是排课的基本单位：一个行政班在一节课上只能有一门课程。

→ [创建班级](/data/classes)

## 教师

<a id="teachers"></a>

菜单：**数据管理 → 教师**（`/data/teachers`）

- 必填项是「姓名」，建议同时填写「工号」与「任教学科」。
- 教师记录会同时用于授课任务的任课教师、调代的申请人与代课人。
- 支持【导入】批量录入，也可【导出】当前名单做备份。

教师本身不能登录系统；需要在 **设置 → 账号**（`/settings/users`）里创建账号并关联教师，教师才能提交调代。

## 课程

<a id="courses"></a>

菜单：**数据管理 → 课程**（`/data/courses`）

| 字段 | 作用 |
|---|---|
| 课程名称 | 课表上显示的名称 |
| 所属学科 | 用于统计与筛选 |
| 连堂设置 | 「允许连堂」表示该课程可以连续两节安排 |
| 课表颜色 | 课表单元格的底色 |

课程是全校共用的目录，不按学期隔离；每学期的差异通过授课任务体现。班会就是普通课程，需要时在课程目录里建一条即可。

## 授课任务

<a id="assignments"></a>

菜单：**数据管理 → 授课任务**（`/data/assignments`）

- 一条授课任务 = 「行政班 + 课程 + 每周节数 + 任课教师」。
- 这是排课唯一的输入：排课只按授课任务里的节数生成课节。
- 没有授课任务的学期排不出课表；录错了就在这里改，不用碰别处。

## 批量导入

<a id="import"></a>

菜单：**数据管理 → 导入**（`/data/import`）。

常用且推荐的两条路：

1. **手动选列导入**（`/data/import/manual`）：上传 Excel / CSV，自己指定哪一列是什么，所见即所得，不调用 AI。
2. **配方导入**（`/data/recipes`）：把一次选列的结果存成配方，下次同格式的文件一键复用。

如果遇到完全没见过的格式，可以点【AI 向导】让 AI 读一遍表头、写出一份配方；配方存好之后，日常导入仍然走上面两条路，不再需要 AI。

教师、年级、行政班等列表页右上角的【导入】按钮则是按模板批量录入，流程一致：

1. 点击【导入】，下载 Excel 模板。
2. 按模板填写数据，注意不要改动表头。
3. 上传文件，系统会校验并在导入结果里列出成功与失败的行。
4. 失败行按提示修正后重新导入即可，已成功的行不会重复创建。
