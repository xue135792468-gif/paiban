# 日常调代流程

临时变更分两条路径：**代课**（有人请假，另一位老师接替）与**调课**（想把自己的课换到同班的另一个时间）。下面按角色说明。

## 教师：提交申请

<a id="apply"></a>

1. 登录后进入 **调代 → 调代课**（`/substitutions`），默认在「我的调代」标签页。
2. 选择类型：
   - **代课**：选「请假日期」→「我的课节」→ 可选「期望代课」→ 填原因 → 提交。
   - **调课**：选「调课日期」→「我的课节」→ 在「换到」里选同班目标节次 → 填原因 → 提交。
3. 提交成功后，申请出现在「我的申请」列表。调课会显示「原节次 → 目标节次」，点【方案】可以查看候选方案。

## 教务：审批并生效

<a id="approve"></a>

1. 审批人切到「待审批」标签页。
2. **代课**：核对信息 →【批准】→ 确认代课教师 → 生效；或【驳回】。
3. **调课**：核对信息 →【生成方案】→ 比较最多 3 个方案卡（影响天数、影响教师数、软约束扣分、排序预设）→ 选一个【整单批准】。
   - 方案在 30 分钟内有效；期间课表若已变化，批准会返回冲突，需要重新生成。
   - 整单批准是一个事务：全部课节移动一起生效，任一校验失败则零写入。

审批完成后：

- 相关教师收到站内通知（调课时每人只收到自己那一节；钉钉 / 飞书启用时同步推送）。
- **课表 → 课表查看**（`/timetable`）在「最新」视角下显示「调」或「代」标记，悬停可看原教师、原因与生效日期。
- 「调代记录」新增记录，可按行政班、教师、类型、日期范围查询；调课可展开看全部移动。
- 选择教师后能看到「被代课次数 / 代课次数 / 参与调课次数」三项分开的统计。

## 跨天调课

周五的课在当天找不到出路时，系统会在搜索窗口（默认 7 天）内继续向后找，例如把链条延伸到下周一至周四。

- 方案卡上的「影响天数」会变成 2 或更多。
- 每个涉及日期的班级节数保持不变，校验器会独立复核。
- 如果学校希望只做同日调课，把「调课搜索窗口」设为 1 天即可。

## 常见问题

- **看不到「提交调代申请」表单**：账号未关联教师，请联系教务管理员在 **系统 → 用户管理**（`/admin/users`）中关联。
- **日期选好后「课节」为空**：当天该教师没有课，或课表尚未发布。
- **调课生成方案后没有候选**：看提示的原因码，常见是目标空堂（`TARGET_EMPTY`）、某位老师在该时段有课（`TEACHER_BUSY`）或超出搜索窗口（`TARGET_OUT_OF_WINDOW`）。
- **批准方案提示课表已变化**：说明生成方案后又有新的调代生效。重新生成即可，旧方案不会写入。
- **批准后课表没变化**：确认课表查看页选择的是「最新」视角，而不是「原始」。
- **代课申请一直待审批**：确认学校设置的是「审批模式」；「直接生效」模式下代课提交即生效（调课始终需要审批）。
