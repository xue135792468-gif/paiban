# 日常调代流程

教师临时请假时，从提交申请到课表更新通常只需几分钟。下面按角色说明谁在什么时间做什么。

## 教师：提交申请

<a id="apply"></a>

1. 登录后进入 **调代 → 调代课**（`/substitutions`），默认在「我的调代」标签页。
2. 选择「请假日期」。系统只列出当天你实际有课的课节。
3. 在「课节」中选择要调代的那一节，例如「第 3 节 · 数学 · 高一(1)班」。
4. 如果已经和某位同事说好，在「期望代课」中选中对方；否则留空。
5. 填写「请假原因」，点击【提交申请】。

提交成功后，申请出现在下方「我的申请」列表中，状态为待审批（若学校使用「直接生效」模式则立即生效）。需要时点击【流转记录】查看处理进度。

## 教务：审批并生效

<a id="approve"></a>

1. 审批人进入同一页面，切换到「待审批」标签页。
2. 核对申请人、日期、节次、班级、课程与原因。
3. 点击【批准】，在弹窗中确认「代课教师」——可以沿用申请中的期望代课，也可以改派。
4. 确认后调代立即生效；点击【驳回】则申请结束，课表不变。

审批完成后：

- 相关教师的站内通知会送达（钉钉 / 飞书启用时同步推送）。
- **课表 → 课表查看**（`/timetable`）在「最新」视角下，该课节会显示「代」标记，悬停可看到原教师与代课教师。
- 「调代记录」标签页会新增一条记录，可按行政班、教师、日期范围查询。

## 常见问题

- **看不到「提交调代申请」表单**：账号未关联教师，请联系教务管理员在 **系统 → 用户管理**（`/admin/users`）中关联。
- **日期选好后「课节」为空**：当天该教师没有课，或课表尚未发布。
- **批准后课表没变化**：确认课表查看页选择的是「最新」视角，而不是「原始」。
- **申请一直待审批**：确认学校设置的是「审批模式」；「直接生效」模式下申请不需要审批。
