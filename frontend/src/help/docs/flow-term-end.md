# 期末统计流程

学期结束时，通常需要核对本学期的课时执行情况、代课次数，并把课表归档。系统不提供独立报表模块，以下操作都在现有页面完成。

## 1. 核对调代记录

<a id="stats"></a>

进入 **调代 → 调代课**（`/substitutions`），切换到「调代记录」标签页：

1. 按「行政班」「教师」或日期范围筛选。期末统计建议把日期范围设为整个学期。
2. 列表会显示每条记录的生效日期、行政班、课程、原教师、代课教师、教室与状态。
3. 选择某位教师后，筛选卡片下方会显示汇总：

   - **被代课 N 次**：该教师请假、由他人代上的节数。
   - **代课 N 次**：该教师替他人上课的节数。

这两个数字是课时统计与代课补贴核算的依据。需要留档时，可直接截图或复制表格内容到 Excel。

## 2. 导出课表

进入 **课表 → 课表查看**（`/timetable`）：

1. 视角选择「最新」，确保包含本学期全部调代。
2. 逐个选择行政班 / 教师 / 教室，点击【导出】→【导出 Excel】或【导出 PDF】。
3. PDF 适合打印归档，页眉带学校名称与校徽；Excel 适合进一步统计。

如果需要「原始」课表作为对照，把视角切到「原始」再导出一次即可。

## 3. 查看通知与操作历史

- **系统 → 通知中心**（`/notifications`）：查看本学期全部调代通知，确认没有遗漏的处理。
- **系统 → AI 操作历史**（`/admin/ai-history`）：如果本学期使用过 AI 数据导入或调代推荐，可在这里查看每次调用记录并导出，便于审计。

## 4. 准备下学期

1. 进入 **教务 → 学期与作息**（`/admin/semesters`）创建下学期，并用【复制】把作息表带过去。
2. 新学期会自动继承课程目录与教师、教室档案；年级与行政班按新学年实际情况调整。
3. 新学期的授课任务需要重新录入，因为「每周节数」和任课教师每学期都可能变化。
4. 完成后再走一遍[新学期开学流程](/help/flow-term-start)。

> 提示：旧学期数据不会被新学期的操作修改。切换「当前学期」只影响之后录入的数据归属。
