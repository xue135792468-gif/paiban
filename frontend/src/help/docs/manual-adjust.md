# 手工调课

自动排课完成后，发布前可以在草稿上手工调整。同班移动或换位直接拖拽；跨班换人用「选中一节课 → 跨班换人 → 双课表预览 → 确认」的入口。两种方式都会自动保存并支持撤销。

入口：**教务 → 自动排课**（`/admin/scheduling`），点击【打开草稿】进入课表草稿页。

## 直接拖拽

- 把课节拖到**同班有课**的格子：两节课直接交换，不再弹出候选列表让你二次选择。
- 把课节拖到**空格**：这节课直接移动，原位留空。
- 拖回原位不产生变更；来源或落点已锁定、落点属于其他班级、同一格有多节课时，系统会明确提示并拒绝，不会替你猜一个目标。
- 直接交换失败（会新增硬冲突）时，系统自动搜索最多 3 个联动方案。方案给出每一步的前后节次、教师、移动课节数、涉及教师数和软分变化；选中并确认后整个方案一起生效，不会只改一半。
- 点击课节后按 Enter 或 Space 也能选中，再用【选择位置】选择目标节次，效果与拖拽相同。

## 锁定课节

<a id="locks"></a>

锁定保护的是**具体某一节授课**的时间与任课教师，不是整门课程。同一门课一周上多次时，每节可以分别锁定。

- 单击课节选中后，用工具栏的【锁定】/【解锁】只处理这一节。
- 点【多选】进入选择模式：点击课节或按 Enter / Space 选择，再点【锁定所选（N）】。选择模式下点击课节不会触发拖拽。
- 点【按范围】可以按**当前行政班的某一天**或**整张班级课表**批量锁定/解锁。下拉里的节数就是实际会操作的已排课节数；确认框会写明班级、范围和节数。
- 批量范围只包含已排课的课节；未排上时间的授课不会有锁标记。一批里混入无效课时，服务端会整批拒绝并说明原因，不会只锁一半。
- 教师视角只支持「所选」范围；要按天或整班批量，请先切到【按行政班】。
- 锁定状态保存在服务端，刷新或重新打开页面后锁标记仍在。锁标记与冲突提示可以同时出现：违规但有位置的课可以锁定，但锁定**不代表合规**，冲突修复前仍然不能发布。
- 锁定的课不能拖拽、换位、跨班换人或撤销回去；需要变更时先解锁。锁定课如果与新规则冲突，系统不会自动解锁或放宽规则。
- 草稿可直接【删除】，删除后进入「最近删除」，7 天内可以在那里恢复（连同锁定一起回来）。

## 基于当前草稿继续优化

<a id="continue-optimization"></a>

草稿上方有【继续优化】入口：以**当前这份草稿**（含手工调整）和已锁定的课节为起点，再跑一次自动排课。

- **会生成另一份新草稿，原稿保留不变**：原稿的课节和版本号都不会被改动，随时可以回来查看。
- 请求会明确带上当前草稿作为来源，不会改用已发布的旧基线或更早的草稿。
- 锁定会继承到新稿：锁定课在新稿里保持原来的时间和任课教师。全部课节都锁定时入口会禁用，并提示没有可优化的课程。
- 任务完成后会显示「打开新草稿」和「与原稿比较」。**任务完成不代表可以发布**：发布仍以新草稿的整稿校验为准，若结果未达发布标准会列出具体阻碍。
- 任务失败或取消时原稿不动，可以修改后重新发起。刷新页面时地址栏里的任务编号只会恢复进度显示，不会重复发起任务。

## 新旧草稿比较

<a id="compare-new-draft"></a>

从优化结果点【与原稿比较】（或打开 `/admin/drafts/新稿?compare=原稿`），会并排显示原稿与新稿，并自动配对两边的课节：

- 摘要写「未锁课节变化 N 节；锁定课节 X 节保持不变」。
- 每行都有锁标记；如果锁定课节发生了变化，会用红色提示，说明数据异常，需要人工检查。
- 两边无法配对的课节会单独计数，不会被当成「没有变化」。
- 比较只作参考，不改变任何草稿；发布仍以整稿校验为准。

## 同班拖动与跨班换人

<a id="intra-class"></a>

### 同班移动 / 换位（拖拽）

同一个行政班的课直接拖拽：拖到空格是移动，拖到同班另一节课是交换节次；任课教师与课程都不变。同一时间有其他班的课是正常的，不影响本班拖拽。

### 跨班换人（显式入口）

<a id="cross-class"></a>

两个不同行政班的两节课交换任课教师，节次与课程都不变。拖拽到别班的课上不会被解释成换老师，必须用这个显式入口。

跨班换人要求两门课程同科目：数学只能和数学换，语文只能和语文换。系统还会核对两位教师的学科是否与对方课程一致；教师或课程没有维护学科时会放行，并在预览里提示。

跨班不提供「换节次」：目标时段属于其他班级时，那节课就是那个班的课，只能换老师、不能换时间。

## 操作步骤

1. 同班调整：直接把课拖到同班目标格；拖到空格是移动，拖到同班课上是交换。
2. 跨班换人：在班级课表里点击一节课，顶部出现「已选」标签，点击【跨班换人】。
3. 右侧抽屉只列出跨班候选。可以按科目、年级、班级、教师筛选；默认只显示可用候选，打开「显示不可用」可以看到每一条不可用原因。
4. 点击一个候选，弹出双课表预览：左右并排显示两位教师的课表，蓝框标出受影响的两节课。用「调整前 / 调整后」切换核对。
5. 点击【确认换课】。系统原子执行；任一硬冲突都会整体拒绝并列出原因，课表不会只改一半。

不用鼠标时，选中课节后点【选择位置】也能完成同班移动/换位；跨班换人仍需上面的显式入口。

## 撤销

<a id="undo"></a>

顶部【撤销】按钮或 `Ctrl+Z` 可以回退最近 20 次调整。移动的逆操作是移回原节次，换课的逆操作是再换一次，一个联动方案作为一步整体撤销。撤销会重新按当前权限、规则和锁定状态校验；如果之后新增了锁定，需要先解锁才能撤销。撤销栈只保存在当前页面会话，刷新后清空。

## 发布之后

<a id="after-publish"></a>

课表发布后基线只读，不能再在草稿上换课。之后的单节课变更走调代流程，见[日常调代流程](/help/flow-substitution)。
