# 手工调课

自动排课完成后，发布前可以在草稿上手工调整。可以直接拖拽课节换位，也可以走「选中一节课 → 显式换课 → 双课表预览 → 确认」的入口；两种方式都会自动保存并支持撤销。

入口：**教务 → 自动排课**（`/admin/scheduling`），点击【打开草稿】进入课表草稿页。

## 直接拖拽

- 把课节拖到**同班有课**的格子：两节课直接交换，不再弹出候选列表让你二次选择。
- 把课节拖到**空格**：这节课直接移动，原位留空。
- 拖回原位不产生变更；来源或落点已锁定、落点属于其他班级、同一格有多节课时，系统会明确提示并拒绝，不会替你猜一个目标。
- 直接交换失败（会新增硬冲突）时，系统自动搜索最多 3 个联动方案。方案给出每一步的前后节次、教师、移动课节数、涉及教师数和软分变化；选中并确认后整个方案一起生效，不会只改一半。
- 点击课节后按 Enter 或 Space 也能选中，再用【调整位置】选择目标节次，效果与拖拽相同。

## 两种换课

<a id="intra-class"></a>

### 同班换位

同一个行政班的两节课交换节次，任课教师、课程与教室都不变。例如把周一第 1 节的数学和周三第 2 节的语文对调。

### 跨班换人

<a id="cross-class"></a>

两个不同行政班的两节课交换任课教师，节次、课程与教室都不变。

跨班换人要求两门课程同科目：数学只能和数学换，语文只能和语文换。系统还会核对两位教师的学科是否与对方课程一致；教师或课程没有维护学科时会放行，并在预览里提示。

跨班不提供「换节次」：目标时段属于其他班级时，那节课就是那个班的课，只能换老师、不能换时间。

## 操作步骤

1. 在班级课表里点击一节课，顶部出现「已选」标签，点击【换课】。
2. 右侧抽屉列出候选，按「同班换位」「跨班换人」分组。可以按科目、年级、班级、教师筛选；默认只显示可用候选，打开「显示不可用」可以看到每一条不可用原因。
3. 点击一个候选，弹出双课表预览：左右并排显示两位教师的课表，蓝框标出受影响的两节课。用「调整前 / 调整后」切换核对。
4. 同班换位如果需要连教室一起换，勾选「同时交换教室」。
5. 点击【确认换课】。系统原子执行；任一硬冲突都会整体拒绝并列出原因，课表不会只改一半。

把课节拖到空位会直接移动并自动保存，不再进入换课预览；需要预览时使用上面的显式【换课】入口。

## 撤销

<a id="undo"></a>

顶部【撤销】按钮或 `Ctrl+Z` 可以回退最近 20 次调整。移动的逆操作是移回原节次，换课的逆操作是再换一次，一个联动方案作为一步整体撤销。撤销会重新按当前权限、规则和锁定状态校验；如果之后新增了锁定，需要先解锁才能撤销。撤销栈只保存在当前页面会话，刷新后清空。

## 发布之后

<a id="after-publish"></a>

课表发布后基线只读，不能再在草稿上换课。之后的单节课变更走调代流程，见[日常调代流程](/help/flow-substitution)。
