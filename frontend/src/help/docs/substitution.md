# 调代课

课表发布后，临时变更分为两类，共用 **调代课**（`/substitution`）入口：

- **调课**：把一个课节从原时间换到同一行政班的另一个节次，并用**置换环**把原节次补满。通常涉及 2–6 位教师，班级当天的课节数量与课程集合不变。
- **代课**：原教师不能上课，由另一位教师接替该课节。只涉及一位教师的变动，不要求回填原节次。

页面是一条三步向导：先选哪节课，再选怎么调，最后核对后提交。

## 选课与提交

<a id="apply"></a>

1. 选「教师 + 日期」，页面画出这一周该教师的课表。
2. 点要调整的那节课（也可以把课卡拖到同班另一节课上，直接预选调课目标）。
3. 在「换老师上（代课）」和「换时间上（调课）」里选一种：
   - **代课**：按同科优先列出候选教师，有冲突的老师会写明原因。
   - **调课**：选目标日期和节次，系统在本班已有课的槽位里找闭合置换环。
4. 看清「课表怎么变」，填原因后提交。

只能调整今天及以后的日期；已经过去的日期不可选，已经上过的课也不能再改。

> 账号需要同时具备「全校课表查看 + 提交调代」权限才能用工作台；普通教师请用「我的调代」自助入口（也需要先在 **设置 → 账号**（`/settings/users`）里关联教师）。

## 生效

<a id="approve"></a>

- **代课**：提交后直接生效；由教务确认代课教师。
- **调课**：由教务生成方案并确认后生效。方案是「一单」，要么整单生效，要么整单不生效，不会出现「张老师换了、赵老师没换」的半截状态。

方案有效期 30 分钟后失效。确认时如果课表已经变化（例如别人先占用了目标节次），系统会提示重新生成，旧方案不会生效。

### 方案卡各字段

| 字段 | 含义 |
|---|---|
| 环长 | 被挪动的课节数，也就是参与置换的课节数量 |
| 影响天数 | 方案涉及的日期数量；同日方案为 1，跨天方案按实际日期去重 |
| 影响教师数 | 被挪动课节的教师去重后的数量；同一教师出现两次只算一位 |
| 软约束扣分 | 按当前启用的软约束与权重计算方案的扣分增量；越小越稳 |
| 排序预设 | 当前采用的排序规则，见下方「排序预设」 |
| 有效期 | 方案可用于确认的最后时间，默认生成后 30 分钟 |

### 搜索窗口与排序预设

在 **设置 → 调代与通知**（`/settings/general`）中配置，保存后立即生效：

- **调课搜索窗口**：默认 7 天，范围 1–30，仅用于发布后调课。先找同一天；当天无解时，向后在该窗口内找跨天方案。草稿换位始终在本周内搜索。
- **最多变动几节课**：默认 6 节，范围 2–10。一次换位方案最多移动这么多节课（环长）；同一教师参与多节时，去重教师人数另计。草稿换位与发布后调课的新方案共用此上限。
- **方案排序**（草稿换位与发布后调课共用）：
  - **最小影响**（默认）：影响天数 → 是否同周 → 影响教师数 → 软约束扣分。
  - **最少教师**：影响教师数 → 影响天数 → 是否同周 → 软约束扣分。
  - **最稳课表**：软约束扣分 → 影响天数 → 是否同周 → 影响教师数。

### 常见无解原因

- `TARGET_EMPTY`：目标节次在本班是空堂。「只挪不补」请直接找教务做低层换时间。
- `TEACHER_BUSY`：某位老师的课在目标节次已有别的班，链条走不通。
- `TARGET_OUT_OF_WINDOW`：目标时间落在搜索窗口之外，可扩大窗口或换目标。
- `NO_SOLUTION`：窗口内没有满足硬约束的置换环。

## 记录与统计

<a id="records"></a>

「调代记录」支持按行政班、教师、类型（调课 / 代课）和日期范围筛选。

- 类型标签区分调课与代课；调课行可以展开，查看该方案的全部课节移动。
- 选择教师后会显示统计：**被代课次数**、**代课次数**、**参与调课次数**、**周课时**、**净课时**。
  - 周课时是发布课表里的固定周节数；代课每次让原教师 −1、代课教师 +1；调课只换时间，不改变周课时。
- 一笔 3 人调课只会增加三位老师的「参与调课次数」，不会虚算成代课。
- 「被代课次数 / 代课次数」只统计代课；期末课时量按净变化计算。

## 课表标记

<a id="notify"></a>

调代生效后，课表「最新」视角会把相关课节标成：

- **调**：调课方案挪动了这一节，悬停可看原教师、原因与生效日期。
- **代**：这一节由另一位教师代课。

「原始」视角始终显示学期初发布的基线，不受调代影响。

## 通知

调代生效都会产生站内通知：

- 调课：每位被卷入教师收到**只关于自己那一节**的通知；班主任收到整单摘要；通知范围含教务时再发给教务。
- 代课：原教师、代课教师、班主任收到通知，范围同上。

通知范围在设置中心配置。管理员还可以维护一份「调代通知收件人」名单（按账号选择，例如校长、年级负责人），调课与代课生效时都会通知他们。启用钉钉时会同步推送，平台不可用时自动降级为站内通知。
