# 调代

调代用于处理「某位教师某一天某几节课不能上」的情况。系统把变更记录为一次调代，而不是直接改课表基线，因此历史可追溯。

菜单：**调代 → 调代课**（`/substitutions`），页面分三个标签页：我的调代、待审批、调代记录。

## 提交申请

<a id="apply"></a>

在「我的调代」标签页填写「提交调代申请」：

1. 选择「请假日期」。系统只列出当天有课的课节。
2. 在「课节」下拉中选择要调代的那一节，显示格式为「第 N 节 · 课程 · 行政班」。
3. 「期望代课」可选：指定一位教师，或留空由审批人决定。
4. 填写「请假原因」，点击【提交申请】。

提交后申请出现在「我的申请」列表中，状态随审批流转变化，点击【流转记录】可以看到每一步的处理人和时间。

注意：账号需要先在 **系统 → 用户管理** 中关联教师，否则页面会提示「当前账号未关联教师，无法提交调代申请」。

## 审批

<a id="approve"></a>

具备审批权限的账号（通常是教务管理员或年级负责人）在「待审批」标签页处理：

- 点击【批准】，在弹窗中确认「代课教师」后提交，调代立即生效。
- 点击【驳回】，申请结束，原课表不变。

审批行为取决于设置里的「审批模式」：

- **审批模式**：申请必须经审批才生效（默认）。
- **直接生效**：教师提交后立即生效，不需要审批。

切换审批模式只影响新提交的申请，已在流程中的申请按提交时的模式走完。

审批生效后，课表查看页对应课节会标注「代」，悬停可以看到原教师、代课教师与原因。

## 通知

<a id="notify"></a>

调代提交、批准、驳回都会产生站内通知，涉及原教师、代课教师与班主任。通知范围在 **设置中心 → 调代与通知**（`/admin/settings`）中配置：

- 当事人（原教师 + 代课教师 + 班主任）
- 含年级组长
- 含教务（增加教务管理员）

点击右上角铃铛可以看到最近通知，或进入 **系统 → 通知中心**（`/notifications`）查看全部。如果学校启用了钉钉或飞书，通知会同时推送到对应平台；平台不可用时自动降级为站内通知。
