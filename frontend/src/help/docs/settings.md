# 设置

菜单：**系统 → 设置中心**（`/admin/settings`）

页面上的所有配置保存后立即生效，无需重启服务。修改后记得点击右上角【保存设置】。

## 学校信息与学校类型

<a id="school-type"></a>

「学校信息」卡片包含：

- **学校名称**：用于课表导出与 PDF 页眉。
- **学校类型**：初中 / 高中。这是一次影响面很大的开关。
- **学校 Logo**：支持 PNG / JPEG，出现在导出的课表页眉。
- **外部访问地址**：例如 `https://paiban.school.cn`，用于通知里的跳转链接。

学校类型的影响：

| | 初中 | 高中 |
|---|---|---|
| 约束强度 | 显示「必须 / 尽量」 | 显示「硬约束 / 软约束」并带权重 |
| 约束模板 | 隐藏 | 可用「存为模板 / 应用模板」 |
| 多草稿比较 | 隐藏 | 可用「比较草稿」 |
| 全校课表视角 | 隐藏 | 可用 |

切换学校类型会改变界面上的可见功能，但不会删除已有数据。切换前建议确认当前学期的排课流程是否依赖这些高级功能。

同一张卡片下方的「调代与通知」区还有「审批模式」（审批模式 / 直接生效）与「通知范围」，说明见[调代](/help/substitution#approve)。

## AI 供应商

<a id="ai"></a>

入口：**系统 → AI 供应商**（`/admin/ai-providers`），设置中心里的「AI 供应商」卡片也指向这里。

配置步骤：

1. 点击【添加供应商】，填写名称、接口地址与密钥。
2. 保存后可点击【测试】验证连通性，或【拉取模型】自动获取该供应商的模型列表。
3. 在供应商卡片下方【添加模型】，可按需配置高级参数（温度、最大 token 等）。
4. 在页面底部「任务分配」中选择模型：
   - **统一模式**：所有 AI 任务使用同一个模型。
   - **分开模式**：数据导入与调代推荐各自选择模型。
5. 点击【保存任务分配】。

没有配置 AI 供应商时，系统其余功能完全可用；只是 AI 数据导入与调代推荐不可用。AI 的每次调用都会记录在 **系统 → AI 操作历史**（`/admin/ai-history`）中，可以追溯与导出。

## 平台切换

<a id="platform"></a>

「IM 平台」卡片用于选择学校使用的即时通讯平台：不启用 / 钉钉 / 飞书。

- 卡片上会显示每个平台的配置状态（已配置 / 未配置），点击【去配置】跳到对应的集成卡片。
- 选择平台后点击【切换平台】，系统会停用原平台并触发新平台的组织同步。
- 切换不会影响班级、课程、课表与调代数据，这些数据完整保留。
- 平台关闭时，通知自动降级为站内通知，系统仍可完整使用。
