# 设置

菜单：**设置 → 学校**（`/settings/general`）

页面上的所有配置保存后立即生效，无需重启服务。修改后记得点击右上角【保存设置】。

## 学校信息

<a id="school-type"></a>

「学校信息」卡片包含：

- **学校名称**：出现在导出的课表页眉。
- **学校 Logo**：支持 PNG / JPEG，出现在导出的课表页眉。
- **外部访问地址**：例如 `https://paiban.school.cn`，用于通知里的跳转链接。
- **学校类型**：初中 / 高中，会改变界面上可见的高级功能（权重、模板、多草稿对比等），不会删除已有数据。日常使用保持默认即可。

## 调代与通知

<a id="approve"></a>

「调代与通知」卡片决定调代方案怎么找、结果通知给谁：

- **调课搜索窗口**：默认 7 天，范围 1–30；仅用于发布后调课，先找同一天，再向后找跨天方案。草稿换位始终在本周内搜索。
- **最多变动几节课**：默认 6 节，范围 2–10；限制一次换位方案移动的课节数（环长），去重教师人数另计；草稿换位与发布后调课的新方案共用。
- **方案排序**：最小影响 / 最少教师 / 最稳课表，默认最小影响；草稿换位与发布后调课的新方案共用。
- **通知范围**：当事人（原教师 + 代课教师 + 班主任）/ 含教务。

「调代通知收件人」卡片可以额外固定指定账号（如校长、年级负责人），调课与代课生效时都会通知他们。

说明见[调代](/help/substitution)。

## AI 助手

<a id="ai"></a>

入口：**AI 助手**（`/ai`），设置页里的「AI 供应商」卡片也指向这里。

配置步骤：

1. 点击【添加供应商】，填写名称、接口地址与密钥。
2. 保存后可点击【测试】验证连通性，或【拉取模型】自动获取该供应商的模型列表。
3. 在供应商卡片下方【添加模型】，可按需配置高级参数（温度、最大 token 等）。
4. 在页面底部「任务分配」中选择模型，然后【保存任务分配】。

没有配置 AI 供应商时，系统其余功能完全可用；只影响 AI 导入向导与配方生成。每次调用都会记录在 AI 助手的「AI 记录」（`/ai/history`）里，可以追溯原始输出。

## 通知渠道

<a id="notify-channel"></a>

「钉钉集成」卡片用于启用钉钉组织同步与通知。钉钉关闭时，通知自动降级为站内通知，系统仍可完整使用。

## 账号与回收站

- **账号**（`/settings/users`）：创建登录账号并关联教师。
- **最近删除**（`/settings/recycle-bin`）：查看 7 天内删除的数据，可整批撤销。
