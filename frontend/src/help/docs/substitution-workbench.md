# 管理员调代工作台

「调代工作台」是给**教务管理员**用的调代操作台：不需要绑定任课教师身份，就能查看任意教师在某个具体日期的课表，替老师安排代课或同班调课，核对清楚课表怎么变之后再生效。

页面是一条**三步向导**，一次只做一件事：

1. **选哪节课**：先选教师和日期，看这一周的课表，点一节课开始调整；选中后也可以直接把课卡拖到同班另一节课上，快速预选调课目标；
2. **怎么调**：在「换老师上（代课）」和「换时间上（调课）」两张动作卡里选一张，把代课老师或目标时间选齐；
3. **核对并提交**：看清「课表怎么变」，再决定提交审批还是亲自确认。

底部始终显示**已选摘要**，点「修改」随时回到上一步重选；条件没选齐时「下一步」是灰的，旁边会提示还差什么。

菜单：**调代 → 调代工作台**（`/substitutions/workbench`）。教师本人的自助入口仍在[调代功能说明](/help/substitution)页面，两边互不影响；教师账号打开工作台会看到引导提示，回到自助入口即可。

操作门槛：账号需要同时具备「全校课表查看 + 提交调代 + 审批调代」权限。只有其中一项（例如只能查看调代记录）不能在工作台发起或确认操作。

## 只改所选日期那一节

<a id="one-time"></a>

工作台里的每一次调代都以「**一次授课**」为单位，记住这条就不会用错：

- 你选定的是某位老师**某个具体日期**的一节课（例如下周三第 1 节），提交的代课或调课**只改变这一天这一节**。
- **下周同一节次自动恢复常规课表**：临时安排不会延续成每周固定的安排。如果想长期换课，那不属于这里的能力，要在排课草稿里调整并重新发布。
- 方案涉及跨天、跨周时（例如周三的课换到周五），每一步都写明**实际日期**；第③步的迷你周表按周画出每一处变化，照着编号逐格核对就不会调错周。
- 同一周同一节次在不同周日期是彼此独立的课：你可以分别对「这周三」和「下周三」的同一节课做不同安排。

## 五种操作怎么选

<a id="concepts"></a>

| 场景 | 用什么 | 系统做什么 |
|---|---|---|
| 某位老师临时请假 | **指定代课** | 只换教师：课程、班级、时间、教室都不动。候选优先列同科教师；跨科可以选但会有提示；有冲突的教师会写明冲突原因，服务端仍会把关 |
| 想把某节课挪个时间 | **调课（同班置换）** | 指定目标日期和课节，系统在本班已有课的槽位里找一个闭合置换环（2 人环或多人环），整环一起生效，班级每天节数不变 |
| 计划又变了 | **再次修订** | 还没开课的课可以继续调整：把代课人从 B 改成 C，或在已调课的基础上再调一次。每次修订都是新版本，历史完整保留 |
| 不需要调整了 | **恢复基线** | 把这节课改回学期初的原始安排（原教师、原时间）。它同样要经预览和校验，不删除历史记录 |
| 想查过去 | **历史版本** | 每次申请与修订都留痕：谁发起、谁批准、前后教师与时间。统计只按当前有效安排计算，改回去不会重复计数 |

判断口诀：换人找「指定代课」，换时间找「调课」，反悔找「恢复基线」，中间变卦走「再次修订」，追责查「历史版本」。

在第②步里，「指定代课」对应动作卡**换老师上（代课）**，「调课」对应动作卡**换时间上（调课）**；选错了不用返回，用表单上方的**虚线切换链接**直接换方向。选「换时间上」时会出现**窗口日期块**：从来源课那天起、含当天共 7 天，周末置灰不可选；点一个日期，下面只列出该班当天已有课的节次——空格只挪不补，不在调课范围内。「再次修订」发生在再次调整已生效的课节时（第③步会出现修订横幅），「恢复基线」按钮在代课候选下方。

## 提交审批还是亲自确认

<a id="approve"></a>

第③步核对无误后，页面底部有两条路（按钮旁写着各自的效果）：

- **提交审批**：申请进入「待审批」队列，课表**不变**，等其他有审批权的教务处理。适用于需要另一位教务复核的场合——即使你自己有审批权限，提交审批也不会自动通过。
- **亲自确认**：你本人就是审批人，走与普通批准完全相同的校验（冲突、约束、开课截止）后立即生效。适合紧急安排。

无论哪条路，都要过两道闸：

1. **权限**：发起需要「提交调代」权限，确认生效还需要「审批调代」权限。操作记录按真实账号保存发起人、代发对象与审批人，不会混用你绑定的教师身份。
2. **开课截止**：**开课后不能再改**。截止时间按这节课（以及方案里全部受影响课节）最早的开课时刻计算，恰好开课或之后都会被拒绝；当天还没开课时仍然可以调整。只能调整今天及以后的课；更早的日期与课卡不可选。

## 左右对照与变化清单

<a id="compare"></a>

第③步把「课表怎么变」直接画出来，不用再在左右两栏之间来回比对：

- 每个受影响的周画一张**迷你周表**：变化的格子淡蓝底、带圈编号，格子里**旧安排画删除线，绿色是新安排**；跨周的方案分成「本周」「下周」两排，同屏看完。
- 表格上方是**编号图例**，每条写明「课程：从哪个槽位挪到哪个槽位」，照着编号逐格核对就不会调错周。
- 想逐字核对时，展开「**文字明细**」变化清单：一张「原来 → 改后」对照表（只列变化项，末行注明其余不变）加「谁会受影响」的人清单。
- 调课可能有多个候选方案，用顶部的**方案 A/B 页签**切换，格子、图例和明细会跟着换。
- 跨科代课会出现黄色提示，需要勾选「**我已知晓，可以跨科**」才能提交。
- 方案有**保留时间**（页面写明到几点）；过期后不用重选，回到第③步点「重新生成」就按最新课表重算。
- 预览是**零副作用**的试算：返回上一步、无解或校验失败，都不会产生申请、生效安排或通知。
