# 新学期开学流程

新学期开始时，按下面 7 步走一遍，就能得到第一份正式课表。初始化向导（`/onboarding`）会按同样的顺序提示你，并显示每一步是否完成。

> 学期之间的数据严格隔离。开始前先确认顶部的「当前学期」是新学期，否则录入的数据会落到旧学期。

## 1. 学校信息

<a id="school"></a>

进入 **设置 → 学校**（`/settings/general`），填写学校名称、上传校徽。这些信息会出现在导出的课表页眉，建议开学前一次配好。

## 2. 学期与作息表

<a id="periods"></a>

进入 **数据管理 → 学期与作息**（`/data/semesters`）：

1. 点击【新建学期】，填写学期名称、开始日期、结束日期。
2. 对新学期点击【设为当前】。
3. 点击【作息表】进入编辑页，配置每天几节课、哪些星期上课。

作息表决定排课可用的课节（星期 + 第几节），后续所有课表都基于它。上学期配置好的作息可以用【复制】带到新学期。

## 3. 年级与行政班

<a id="grades"></a>

先到 **数据管理 → 年级**（`/data/grades`）创建年级，再到 **数据管理 → 行政班**（`/data/classes`）创建班级，填写所属年级、行政班名称、学生人数，可选班主任。

两个页面都支持【导入】批量录入，班级较多时建议用模板一次导入。

## 4. 教师

<a id="teachers"></a>

进入 **数据管理 → 教师**（`/data/teachers`）录入教师名单，至少填写姓名，建议补齐工号与任教学科。支持 Excel 导入。

## 5. 课程

<a id="courses"></a>

进入 **数据管理 → 课程**（`/data/courses`）维护课程目录，重点确认哪些课程「允许连堂」。课程目录全校共用，新学期通常不需要重建。班会按普通课程建一条即可。

## 6. 授课任务

<a id="assignments"></a>

进入 **数据管理 → 授课任务**（`/data/assignments`），逐条录入「行政班 + 课程 + 每周节数 + 任课教师」。

这是排课最重要的输入。录入完成后核对：每个班所有课程的每周节数之和不能超过作息表提供的总课节数。

## 7. 排课规则（可选）

<a id="constraints"></a>

进入 **排课规则**（`/rules`）。规则不是必填项：不写规则也能排课，系统只保证同一教师、同一班级不撞课。有特殊要求时再按「对谁 / 哪些课 / 什么时候 / 要求」拼一条，例如「王老师周五不排课」「八年级数学每天最多 1 节」。

## 完成：排课与发布

<a id="finish"></a>

回到 **课表工作台**（`/workbench`），选择学期与年级，点击【开始排课】。求解完成后【打开草稿】检查冲突、拖拽微调，满意后【发布课表】。

发布后，教师即可在 **课表工作台 → 课表**（`/workbench/timetable`）看到自己的课表。之后每天的临时变动走[日常调代流程](/help/flow-substitution)。
