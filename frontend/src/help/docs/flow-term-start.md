# 新学期开学流程

新学期开始时，按下面 9 步走一遍，就能得到第一份正式课表。初始化向导（`/onboarding`）会按同样的顺序提示你，并显示每一步是否完成。

> 学期之间的数据严格隔离。开始前先确认顶部的「当前学期」是新学期，否则录入的数据会落到旧学期。

## 1. 学校信息

<a id="school"></a>

进入 **系统 → 设置中心**（`/admin/settings`），填写学校名称、学校类型，上传校徽。这些信息会出现在导出的课表页眉，建议开学前一次配好。

## 2. 学期与作息表

<a id="periods"></a>

进入 **教务 → 学期与作息**（`/admin/semesters`）：

1. 点击【新建学期】，填写学期名称、开始日期、结束日期。
2. 对新学期点击【设为当前】。
3. 点击【作息表】进入编辑页，配置每天上午 / 下午 / 晚自习各几节、哪些星期上课。

作息表决定排课可用的课节（星期 + 第几节），后续所有课表都基于它。上学期配置好的作息可以用【复制】带到新学期。

## 3. 年级与行政班

<a id="grades"></a>

先到 **教务 → 年级**（`/admin/grades`）创建年级，再到 **教务 → 行政班**（`/admin/classes`）创建班级，填写所属年级、行政班名称、学生人数，可选班主任。

两个页面都支持【导入】批量录入，班级较多时建议用模板一次导入。

## 4. 教师

<a id="teachers"></a>

进入 **教务 → 教师**（`/admin/teachers`）录入教师名单，至少填写姓名，建议补齐工号与任教学科。支持 Excel 导入。

## 5. 教室

<a id="rooms"></a>

进入 **教务 → 教室**（`/admin/rooms`）录入普通教室、实验室、操场等，填写容纳人数与教室类型。教室类型会影响排课匹配。

## 6. 课程

<a id="courses"></a>

进入 **教务 → 课程**（`/admin/courses`）维护课程目录，重点确认「连堂设置」与「场地设置」是否符合学校实际。课程目录全校共用，新学期通常不需要重建。

## 7. 授课任务

<a id="assignments"></a>

进入 **教务 → 授课任务**（`/admin/assignments`），逐条录入「行政班 + 课程 + 每周节数 + 任课教师」。

这是排课最重要的输入。录入完成后核对：每个班所有课程的每周节数之和不能超过作息表提供的总课节数。

## 8. 约束规则

<a id="constraints"></a>

进入 **教务 → 约束配置**（`/admin/constraints`），确认启用的约束与权重。默认已启用「教师不冲突」「行政班不冲突」「教室不冲突」等基础规则，通常只需按学校偏好调整软约束权重，然后【保存配置】。

## 9. 完成

<a id="finish"></a>

回到 **教务 → 自动排课**（`/admin/scheduling`），填写草稿名称与最大求解时长，点击【开始排课】。求解完成后【打开草稿】检查冲突、拖拽微调，满意后【发布课表】。

发布后，教师即可在 **课表 → 课表查看**（`/timetable`）看到自己的课表。之后每天的临时变动走[日常调代流程](/help/flow-substitution)。
