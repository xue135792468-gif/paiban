- 后端健康检查：<http://127.0.0.1:8080/api/health>

## 建议测试顺序

### 0. 准备一个干净学期

1. 左侧「学期与作息」→「新建学期」。
2. 名称填 `2026-2027 学年第一学期`，开始 `2026-09-01`，结束 `2027-01-20`，保存。
3. 点该学期的「设为当前」。
4. 点「作息表」→「生成默认作息」→「保存作息表」。
   - 默认是周一至周五、上午 4 节、下午 4 节、晚自习 2 节。

### 1. 传统教师导入（先验证一期功能没有退化）

1. 左侧「教师」→「导入」。
2. 选择 `teachers-standard.xlsx`，先预览再确认导入。
3. 预期：得到 5 位教师（张三、李四、王五、赵六、孙七），工号 T001–T005。

### 2. 建最小排课数据

按顺序创建：

1. 「课程」：语文（学科语文）、数学（学科数学）。
2. 「教室」：普通教室，容量 50。
3. 「年级」：初一。
4. 「行政班」：初一 1 班，学生 45 人。
5. 「授课任务」：
   - 初一 1 班 · 语文 · 张三 · 每周 5 节
   - 初一 1 班 · 数学 · 李四 · 每周 5 节

### 3. 自动排课与发布

1. 左侧「自动排课」→「开始排课」。
2. 等状态变成「已完成」（约几秒到十几秒）。
3. 点「打开草稿」，在草稿编辑器里拖拽一节课，观察冲突提示。
4. 点「发布课表」→ 确定。
5. 左侧「课表查看」，切换行政班 / 教师 / 教室视角，确认能看到刚发布的课。

### 4. AI 数据导入（需要先配置 AI 供应商）

如果暂时没有 API Key，可以跳过本节；系统其余功能不依赖 AI。

1. 「设置中心」→「AI 供应商」→「去配置」。
2. 添加供应商：
   - DeepSeek：协议「OpenAI 兼容」，Base URL `https://api.deepseek.com`，模型 `deepseek-chat`（不支持视觉）。
   - Gemini：协议「Gemini」，Base URL `https://generativelanguage.googleapis.com/v1beta`，模型 `gemini-2.0-flash`，勾选「支持视觉」。
   - Anthropic：协议「Anthropic」，Base URL `https://api.anthropic.com`，模型 `claude-sonnet-4-5`，勾选「支持视觉」。
   - Base URL 规则：OpenAI 兼容填 API 根地址（系统追加 `/chat/completions`，OpenAI 官方通常填到 `/v1`）；
     Anthropic 填 `https://api.anthropic.com`（系统追加 `/v1/messages`，填到 `/v1` 也可以）；
     Gemini 填版本前缀（系统追加 `/models/{模型}:generateContent`）。
3. 保存后点「连接测试」，确认返回成功。
4. 在「任务分配」里：
   - 统一模式：所有任务用同一个模型；
   - 分开模式：`数据导入` 选 Gemini（图片识别需要视觉模型），`调代推荐` 选 DeepSeek。
5. 左侧「AI 数据导入」：
   - **Excel/CSV**：上传 `teachers-messy.xlsx`，点「开始解析」。
   - **粘贴文本**：把 `teachers-text.txt` 的内容粘进去。
   - **上传图片**：上传 `teachers-photo.png`（必须选支持视觉的模型）。
6. 预期：
   - 出现目标格式预览表（姓名/工号/电话/邮箱/学科）；
   - 低置信度单元格浅黄底色；
   - 右侧有 AI 映射说明。
7. 试三种收尾：
   - 「全部接受并入库」：直接写教师；
   - 「手动微调」：改一个单元格 →「AI 继续」或「直接入库」；
   - 「打回重析」：重新调用 AI。

> 注意：如果先用传统导入建了张三、李四等教师，再用 AI 导入同一批名字，入库校验会报「姓名与学科重复」。
> 想完整走通 AI 入库，建议先重置数据（见文末），或者只保留 AI 导入这一条路径。

### 5. AI 调代推荐（需要 AI 供应商 + 一条待审批申请）

1. 「用户管理」→「新增用户」：
   - 用户名 `teacher1`，密码 `teacher123`，角色「教师」，关联教师选「张三」。
2. 退出 admin，用 `teacher1` / `teacher123` 登录。
3. 「调代课」→「我的调代」→ 选一个**当天有课**的日期（如果下拉为空就换一天）→ 选课节 → 填原因 →「提交申请」。
4. 退出，用 admin 登录。
5. 「调代课」→「待审批」→「批准」。
6. 在批准弹窗里点「AI 推荐代课人」：
   - 未配置供应商时按钮是灰的，悬浮提示「请先在设置中配置 AI 供应商」；
   - 配置后返回最多 3 位候选人 + 理由 + 评分；
   - 点「选择」会自动填入代课教师，再点「确认批准」。
7. 回到「课表查看」，确认该课节出现「代」标记。

### 6. AI 操作历史

1. 「设置中心」→「AI 操作历史」。
2. 按时间、操作人、任务类型、供应商筛选。
3. 点「详情」：
   - 导入记录：文件、原始 AI 解析、用户确认、入库结果；
   - 调代记录：请假教师、课程、日期、AI 推荐的 3 人、最终代课教师。
4. 右上角「导出 Excel」「导出 PDF」，确认能下载。

### 7. 初中 / 高中模式

1. 「设置中心」→「学校类型」选「初中」→「保存设置」→ 确认刷新。
2. 预期：
   - 约束配置只剩「必须 / 尽量」两档，没有权重数字和模板按钮；
   - 课表查看没有「全校」视角；
   - 草稿编辑器没有「比较草稿」；
   - 设置中心隐藏「同步策略」。
3. 切回「高中」，以上功能恢复。

## 常见问题

- **AI 功能按钮是灰的 / 提示未配置**：先去「设置中心 → AI 供应商」配置并保存，再刷新页面。
- **图片导入提示模型不支持视觉**：把「数据导入」任务分配给标记了「支持视觉」的模型（Gemini）。
- **调代申请下拉为空**：所选日期没有该教师的课；换一个与课表星期匹配的日期。
- **排课一直排队**：求解器同一时刻只跑一个任务；等当前任务结束，或到「自动排课」页面取消旧任务。
- **导入校验报重复**：同一批数据里工号或「姓名+学科」重复，或数据库里已存在同名同科教师。

## 重置测试数据

系统运行期间不要直接删数据库文件。先停止：

```bat
停止排课系统.cmd
```

然后把当前库移走（不要直接删，留作对照），再启动：

```bat
move backend\data\paiban.mv.db backend\data\paiban.mv.db.testrun
启动排课系统.cmd
```

应用会用 Flyway 重新建一个空库。测试前的旧库备份在
`backend/data/paiban.mv.db.bak-20261021-005949`。
