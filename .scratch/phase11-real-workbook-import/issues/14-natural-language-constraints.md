# 14: 自然语言生成约束（正式规格已发布，未实现）

**What to build:** 用自然语言描述排课要求（如“周三下午语文组教研不排课”“王老师周三下午不排”），生成用户可校对、勾选的约束建议，确认保存后参与排课。无法准确表达的要求明确列出，不静默近似。**当前只有开关占位**：`ai.features.natural-language-constraints` 常量在、设置页有一行「自然语言生成约束」且开关是灰的「即将推出」，后端没有任务槽、没有接口、没有服务、没有测试，打开也不会发生任何事。

**Blocked by:** 无未完成的票10代码前置；多条约束保存已具备。正式规格已发布，待to-tickets明确基础能力及AI/恢复/审计的阻塞关系；尚未拆实现票，不能按原灰开关小票直接开工。

## 已确认（2026-10-27，第一轮 Q1–Q5，用户“按你推荐的来”）

- 首期包含输入、生成建议、用户校对与勾选、确认保存并参与排课的完整流程。生成本身不改变业务配置，取消不改变原有配置。
- 第一轮确认只转换现有目录；随后用户已明确同意补充“课程禁排时段”作为本期基础能力，范围调整为现有24类＋这一新增类型，不引入任意新规则或自定义 DSL。其余无法准确表达的句子仍列为“暂不支持”或“未转换”，不能生成相近但含义不同的约束。
- 同名对象由用户在结果中选择；缺失条件在结果中补齐，同时保留已明确的其他建议。由本学期作息能唯一确定的“下午”等表达可展开，不能猜对象或缺少标准的数量。
- Agent 先拟 20 句合成学校场景及预期结果，用户校对含义、补充真实说法；验收同时核对结构和语义。
- 新增独立AI任务槽 `NATURAL_LANGUAGE_CONSTRAINTS`，沿用供应商/模型配置，用同一组语料评测现有可用模型后决定绑定。每次生成最多等待60秒；第五轮已明确本轮模型评测总费用上限20元，价格不可靠则不调用。
- 允许向已配置供应商发送理解本次要求必需的要求原文及相关教师、课程、行政班名称，不附带手机号等无关资料。此决定不等同于已经执行外部评测。
- 第一轮曾沿用 ADR-0028 的同类共用控制；第三轮 Q8 用户同意每条要求独立必须/尽量、未单独设置则沿用同类默认；第四轮又确认逐项启停和软约束重要程度。类型保留总开关及默认值，同组多个课节共用这项要求的控制。手动与AI都支持，ADR-0028已记修订，尚未实现。
- 对象引用按现有领域归属校验：教师/课程是有效全局资产；行政班属于选定学期；节次属于该学期作息。明确全体范围须使用显式条目，空列表不表示全体。

## 第二轮进度与当前实现事实

- **Q7 已确认**：支持新增及明确确认后的替换；完全重复标为已存在，不再添加；同作用域阈值、同课程教室要求等不兼容时比较新旧值，默认保留旧值。自然语言删除留后续，仍可手工删除。
- **Q9 已确认**：按独立要求勾选；同一半天展开的多个课节整体分组，全局与例外关联展示；独立要求可以分别选择，部分明确的建议不因其他项含糊而丢弃。
- **Q10 已确认范围扩展**：用户认可20句语料讨论基准，并在确认手动可多选课节后明确答“那就这样做吧”。新增“课程禁排时段”：选课程、选每个上课日或指定星期、多选当前学期作息中的课节；支持连续与不连续课节。自然语言填充与手动配置共用同一结果，可继续改选再保存；同一要求的多课节分组展示、修改与删除。具体场景包括“体育课不排上午第1、2节”“化学周五第八节不排”。这项尚未实现。
- `PUT /api/constraints` 提交整学期完整配置，缺失类型会删除；不能单独提交新增建议作为完整配置。
- **Q6 已确认**：AI先帮填表，检查后点“添加到约束表”，仍可修改；最后统一点击“保存”才生效，保留此前手工修改并明确标记未保存。
- **Q8 已确认**：每条要求可单独设置必须/尽量，默认沿用同类设置，不因新要求改变其他已有项；多课节同组共用这项要求的设置。ADR-0028已记设计修订，当前代码尚未变更。
- **Q11 已确认**：多人同时修改时检测配置变化，保留自己的修改与建议，读取最新配置供核对后再保存，不悄悄覆盖。
- **Q12 已确认**：输入、生成结果和待保存修改可在刷新/离开返回后恢复，恢复不等于生效，不同学期分开；生成超时或失败保留输入，由用户主动重试，不自动反复调用。
- **Q10 待实现事实**：当前代码仍无课程禁排具体课节类型。课程禁排时段已纳入设计范围，不再以“暂不支持”作为该场景的目标验收结果；实施时须先补基础配置及各评估入口，再接自然语言。
- **Q13–Q16 已确认**：每条要求可暂停保留；类型总开关重开保留逐项状态；软要求可单独调重要程度，AI不任意编数值；同一限制同一事实不重复计分、硬优先/全软取最高重要程度；阈值先按对象例外替代全局，放宽原限制需明确提示并确认。
- **Q17–Q18 已确认**：未完成内容按账号/学期保存并跨设备恢复，相互隔离；约束管理权限可生成/编辑/保存并看自己的生成记录，设置管理权限可配模型和看全局追溯。原话、模型结果、用户修改/选择、最终保存关联记录，取消仍保留调用记录。
- **Q19–Q23 已确认**：明确禁令按必须、“尽量/优先/最好”按尽量，无强度表述则用默认并展示；编辑不调模型，重生成留历史且不覆盖已加入内容，取消/60秒超时后的晚响应只记记录；添加/恢复/保存复核对象与作息，不静默换对象或扩大范围；初中模式开放教研禁排及按需重要程度调整，AI不可用保留原因提示及手动配置；22句各3次、明确支持整句语义正确率≥95%、歧义等零误转，最多比较2模型、评测总预算20元、价格不可靠则不调用。
- 本轮Q1–Q23已答，用户明确要求执行to-spec，正式规格已发布。设计归纳和确认记录保留来源，当前待to-tickets，未拆实现票。

## 验收

- [ ] 固定22句（C01–C22）各重复3次：18句可直接转换的明确支持场景共54次，至少52次整句语义完全正确（≥95%）；C16/C17/C19/C20共12次必须零误转。
- [ ] 对象、课程、星期、课节、数量与必须/尽量都正确才计整句成功；歧义不猜、范围不扩大、不支持不编造，混合句的明确部分保留。
- [ ] 课程禁排支持手动多选、同组修改/删除，和自然语言填表结果一致；逐项控制、重叠、例外在各评估入口和模板一致，旧配置含义不变。
- [ ] 生成/编辑/加入约束表不直接改变生效配置，统一保存后生效；保存与审计原子一致，失败零部分写入。
- [ ] 恢复、并发核对、权限隔离、取消/超时/晚响应符合已确认场景，记录原始输出与用户最终改动分别保留。
- [ ] 最多比较2个现有可用模型，评测总费用≤20元，可靠单价/费用上界未知则不调用。固定集通过只证明该语料范围，不能宣称任意语句均可转换。
