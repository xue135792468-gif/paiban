# 14: 自然语言生成约束（构想，未实现）

**What to build:** 用一句话描述排课要求（"周三下午语文组教研不排课""王老师周三下午不排""体育不排第一节"），系统把它转换成约束配置。**当前只有开关占位**：`ai.features.natural-language-constraints` 常量在、设置页有一行「自然语言生成约束」且开关是灰的「即将推出」，后端没有任务槽、没有接口、没有服务、没有测试，打开也不会发生任何事。

**Blocked by:** `10-multiple-constraint-targets`（自然语言天然产生多条：多位老师各自禁排、多门课指定教室；现在每种约束只能存一条，做了也存不下）

**Status:** needs-triage

## 建议形态（待用户确认）

- 只生成**建议**，不直接写库：约束页输入一句话 → 后端返回「约束类型 + 参数 + 硬/软 + 权重 + 一句解释」，外加「无法识别 / 有歧义」清单 → 页面展示 diff，用户逐条勾选 → 走现有保存接口。
- 新增 AI 任务槽 `NATURAL_LANGUAGE_CONSTRAINTS`，沿用现有供应商/模型绑定与 `ai_task_config`。
- 护栏：只允许 `ConstraintType` 声明过的类型与参数；id 必须存在于本学期的教师/课程/班级；不覆盖已有条目（除非用户勾选替换）；数值越界直接拒绝并说明范围。
- 软硬由用户确认，AI 只建议。

## 验收

- [ ] 一组 10–20 句真实说法，逐句断言生成的类型与参数（这是功能可用的唯一证据，单个 demo 不算）
- [ ] 无法识别的句子必须进"未转换"清单，不能编造
- [ ] 生成结果需要用户确认后才写入，且能在页面上取消
