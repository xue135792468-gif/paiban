# 04: 自动分类与多类入库

**What to build:** 一次上传、一次确认，系统按识别结果同时写入教师、课程、行政班与课表。教师只要求姓名，缺的字段留空；同名实体只补空字段；某一类失败时已经建好的类别保留并可单独重试。

**Blocked by:** 03

**Status:** done

- [x] 预览确认后按「教师 → 课程 → 行政班 → 课表」顺序写入，课表产物仍为 `DRAFT` 草稿
- [x] 教师只要求姓名，工号/手机/邮箱/学科有则填、无则留空
- [x] 行政班缺少年级时按班级名推断，推断出的年级不存在则创建
- [x] 同名教师（按姓名）、课程（按名称）、行政班（按名称）补齐空字段，不覆盖已有值
- [x] 某一类写入失败时，已成功类别保留，失败类别单独报告并可重试
- [x] 缺少当前学期时给出跳转入口；缺少课节时给出「一键生成默认作息（上午 4 + 下午 4，周一至周五）」
