# 02: 课表工作台与已发布课表层级收口及术语翻译

**What to build:** 优化课表工作台与已发布课表页的视觉层级和可读性：工作台移除右上跨模块的「导入课表」按钮，将「发起排课任务」表单整理为整齐两行（第一行排课年级与草稿名称，第二行最大求解时长与右对齐唯一主按钮「开始排课」）；任务卡片在无冲突完成态默认折叠为单行绿色摘要（带「展开详情」和「打开草稿」），而在运行中、有冲突或失败时保持完整展开；草稿列表的「求解得分」列改为「冲突情况」（主显「无冲突」或「N 处冲突」，悬停看得分）；「排课历史」降级为草稿表下方默认折叠的汇总栏，但在当前学期尚无草稿且最近一次任务失败或被取消时自动展开；已发布课表页删除副标题里与 `ⓘ` 重复的调代长句，并将「导出」上移到标题行右上角使控制条在 1440px 下保持单行。

**Blocked by:** None (can start immediately)

**Status:** in-progress

- [ ] 课表工作台不再展示右上跨模块的「导入课表」按钮，「开始排课」在两行表单右下角对齐且无孤立换行
- [ ] 「当前排课任务」在无冲突完成态默认收起为单行绿色摘要并支持点击「展开详情」；运行中、有硬冲突或失败态自动保持完整展开
- [ ] 课表草稿列表将「求解得分」列改为「冲突情况」，主显「无冲突」或「N 处冲突」（悬停提示原求解得分），不再在主单元格暴露 `hard/soft`
- [ ] 「排课历史」收拢在「课表草稿」下方并默认折叠；当草稿为空且最近一次排课任务为失败或取消时自动展开，确保异常原因不被隐藏
- [ ] 已发布课表页将「导出」移动至标题行右上角，删除副标题中重复的调/代说明文本（保留 `ⓘ`），1440×900 下筛选控制条单行不换行
- [ ] 保持工作台与课表页相关 SFC 行数不突破仓库体积基线上限
- [ ] 补齐工作台任务折叠/历史自动展开与课表页单测，并同步更新排课与空态相关 Playwright E2E 用例至通过
