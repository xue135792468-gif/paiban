# 03: 统一数据导入主入口、拖拽上传校验与 AI 渐进增强

**What to build:** 将数据导入入口的主次彻底反转：进入数据导入时默认展示零 AI 依赖的「手动选列 / 配方」通道，使用全站统一的拖拽上传区替代原生文件选择按钮并消除重复文件名展示；选入非 `.xlsx/.xls/.csv` 文件时立刻在上传区下方给出明确的红色格式报错而非静默置灰；将手动列映射中的「表头行」「复合键（班级|星期|节次）」「复合键列」「班级/星期/节次分列」翻译为白话（「标题所在行」「合并在一列（如 班级|星期|节次）」「合并信息列」「拆成三列（班级、星期、节次分开）」）；顶部提供「AI 智能解析」渐进增强切换，未配置 AI 时呈现干净一屏引导，已配置时彻底隐藏 3 张「即将支持」占位卡，且支持 URL 携带 `?session=`、`?target=`、`?mode=ai` 自动切入 AI 模式、存在未完成会话时显示顶部恢复横条，并保留旧手动导入路径向后兼容。

**Blocked by:** None (can start immediately)

**Status:** in-progress

- [ ] 数据导入默认入口直接展现「手动选列 / 配方」拖拽上传区，零 AI 配置即可上传文件、映射列、套用或保存配方并导入
- [ ] 手动与 AI 上传均使用统一拖拽区（无浏览器原生文件按钮，无文件名重复显示），选入非 Excel/CSV 文件立即在上传区下方输出包含当前后缀与支持格式的红色内联错误提示
- [ ] 手动选列映射界面的工程术语全部替换为定稿白话（「标题所在行」「合并在一列（如 班级|星期|节次）」「合并信息列」「拆成三列（班级、星期、节次分开）」）
- [ ] 顶部支持「手动选列 / 配方」与「AI 智能解析」切换；未配置 AI 时切入 AI 仅展示引导卡（「去 AI 助手配置」与「返回手动导入」），不展示禁用目标卡片
- [ ] 已配置 AI 时仅展示「整本工作簿」「教师」「课表」3 个可用目标，彻底隐藏行政班、课程、授课任务 3 张「即将支持」卡片
- [ ] URL 携带 `?session=`、`?target=` 或 `?mode=ai` 时自动切入 AI 模式并恢复对应上下文；存在未放弃 AI 导入会话时页顶展示轻量恢复提示横条；原手动导入地址继续兼容可用
- [ ] 导入视图与组件严格满足 600 行 SFC 体积限制（新增模式/卡片逻辑拆分子组件）
- [ ] 补齐格式校验、白话映射与模式切换单测，并更新 AI 导入、手动导入与配方相关 Playwright E2E 用例至通过
