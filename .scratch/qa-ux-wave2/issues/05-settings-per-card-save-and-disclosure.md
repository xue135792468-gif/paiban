# 05: 设置页按卡显式保存与低频配置分层

**What to build:** 澄清设置中心保存归属并分层低频配置：删掉页头歧义的全局「保存设置」按钮，为学校信息、调代与通知策略、通知收件人、钉钉集成、AI 特性与阈值各自提供明确的卡片级保存按钮，复用后端局部合并设置接口且不改后端代码；在钉钉集成卡片点「保存钉钉配置」时，由前端一并提交同一卡片内的「事件令牌」配置键值，彻底修复跨接口漏存隐患；将「外部访问地址」折叠进学校信息卡片的「高级设置」，钉钉集成开关关闭时折叠凭据与事件令牌表单，并在 AI 特性卡片隐藏灰态不可用的「代课人选推荐 · 即将推出」占位行。

**Blocked by:** None (can start immediately)

**Status:** in-progress

- [ ] 设置中心页头不再展示全局「保存设置」按钮，学校信息、调代与通知策略、通知收件人、钉钉集成、AI 设置各卡均拥有独立显式保存按钮且保存后给出清晰成功提示
- [ ] 修改学校信息或调代策略并点击对应卡片保存时，仅更新该卡片所属配置键值，互不覆盖且刷新后持久化生效
- [ ] 钉钉集成开关未启用时默认折叠 AppKey/AppSecret/AgentId/CorpId/事件令牌；启用后完整展开，点击「保存钉钉配置」同时保存钉钉集成配置与「事件令牌」，刷新后两者均保留
- [ ] 学校信息卡片中的「外部访问地址」默认折叠在「高级设置」内，可按需展开编辑并随学校信息一并保存
- [ ] AI 特性卡片不再渲染禁用的「代课人选推荐 · 即将推出」占位行，保留「自然语言生成约束」开关与导入低置信度阈值
- [ ] 设置页 SFC 行数不超过仓库既有基线（优先拆出学校信息/AI 特性子卡片保持整洁）
- [ ] 补齐按卡局部提交与钉钉事件令牌协同提交单测，并更新设置策略 Playwright E2E 用例至通过
