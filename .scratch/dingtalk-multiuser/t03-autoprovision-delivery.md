# 03-A3 本地身份解析与密码恢复保护交付

2026-11-11。整票尚待前端整合、真实浏览器与双轴复查，本记录不表示整票放行。

## 实现

`DingTalkAccountProvisioner` 在第三方身份取回之后开启本地事务：共享账号锚点→按教师 ID 顺序锁定并刷新→UID 优先 / 未绑定唯一同名→保护检查→复用启用账号或创建无密码老师账号→分别写系统开号与配对审计。仅停用账号、管理员首次弱绑定、歧义均在写入之前拒绝。多个历史启用账号固定选最小 ID；自动账号名碰撞生成有界后缀，不复用无关账号。

`DingTalkLoginFailure` 使用现有 ApiException.details 的 `code`，不新增全局异常处理框架。人工建号也取得同一锚点，防止管理员关联出现在首次绑定中途。

密码总钥匙保护在现有 `AccountMutationGuard` 中加入启用 PASSWORD 超管标量计数。降级、编辑停用、专用停用、同步停用统一受保护；存在钉钉超管仍不得移除最后的密码恢复入口。另一个密码超管存在时允许替换。决策见 ADR-0036。
