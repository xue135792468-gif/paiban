# 03: 钉钉免登自动开号、唯一同名配对与说明页

**What to build:** 老师在钉钉打开应用即自动开通「老师」账号并登录；未绑定时按钉钉姓名找唯一同名档案当场配对；进不去时显示说明页（按原因码），不再静默退回密码页。钉钉免登账号无密码、拒绝密码登录。见 spec「账号与登录」。

**Blocked by:** 01, 02

**Status:** implemented

04整改后两个轴均已复核并放行；03从集成dd5cba1启动，按 `../t03-wire-contract.md` 分片。产品确认已生效，不再重复询问。迁移盘点最高V61，V62仅保留给本票登录类型迁移。

- [x] 免登流程按 spec 四步：userId 命中 → 唯一同名且未绑定则配对 → 有启用账号登录 / 仅停用账号报「已停用」/ 无账号自动建老师账号
- [x] 2026-11-11用户确认的保护：人工修改教师钉钉ID仅超级管理员可操作；教务普通档案编辑仍可用，UID无变化不误拒；导入等入口同样不得绕过
