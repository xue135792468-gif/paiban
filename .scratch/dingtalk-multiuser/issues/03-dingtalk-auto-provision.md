# 03: 钉钉免登自动开号、唯一同名配对与说明页

**What to build:** 老师在钉钉打开应用即自动开通「老师」账号并登录；未绑定时按钉钉姓名找唯一同名档案当场配对；进不去时显示说明页（按原因码），不再静默退回密码页。钉钉免登账号无密码、拒绝密码登录。见 spec「账号与登录」。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 免登流程按 spec 四步：userId 命中 → 唯一同名且未绑定则配对 → 有启用账号登录 / 仅停用账号报「已停用」/ 无账号自动建老师账号
- [ ] 配对与开号同一事务，各写审计（操作者「系统（钉钉免登）」）
- [ ] 登录失败返回结构化原因码：未开通、无法确认身份、已停用、钉钉未启用、钉钉调用失败
- [ ] 前端说明页按原因码展示（未开通 / 无法确认 → 请联系教务处；已停用 → 账号已停用），含「我是管理员，用密码登录」小入口
- [ ] 钉钉免登账号无密码：密码登录拒绝并提示「请在钉钉中打开」；账号页不提供设置密码
- [ ] 被提升为管理员的老师仍走钉钉免登
- [ ] 更新 `DingTalkAuthProvider` 注释（推翻「绝不自动开号」）
- [ ] 集成测试（假钉钉）：已绑定 / 唯一同名配对 / 重名 / 不在档案 / 已停用 / 重复打开不重复开号
- [ ] 说明页组件单测覆盖各原因码
