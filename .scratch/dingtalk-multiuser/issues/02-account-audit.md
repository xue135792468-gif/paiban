# 02: 账号操作审计与查看页

**What to build:** 所有账号操作写审计，超级管理员有一个页面可查。复用现有审计日志表。见 spec「审计」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 现有操作补写审计：手工建号、改身份、重置密码、停用、启用、批量导入账号
- [ ] 预留动作类型给后续票：自动开号、钉钉配对（03）、同步停用（04）
- [ ] 每条含操作者、目标账号、动作、变更前 / 后；系统动作的操作者写「系统（钉钉免登）」
- [ ] 审计查看接口与页面：时间倒序、按动作类型 / 目标账号筛选、分页；只有「账号审计查看」权限可访问
- [ ] 集成测试：每类操作各产生一条审计；教务管理员访问 403
