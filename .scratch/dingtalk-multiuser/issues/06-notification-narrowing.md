# 06: 钉钉通知收敛为两类

**What to build:** 钉钉只发：申请人的审批结果（批准 / 驳回附理由）；接课老师的代课生效通知（审批通过与工作台直接生效都发）；工作台调课时被挪动老师各自的调课通知。其余停发，模板与设置项保留但不触发。见 spec「通知」。

**Blocked by:** 05

- [ ] 设置页隐藏「通知范围」「调代通知收件人」
