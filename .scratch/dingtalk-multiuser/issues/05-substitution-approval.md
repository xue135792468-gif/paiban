# 05: 恢复代课审批（待审批 / 批准 / 改人 / 驳回 / 撤回 / 作废）

**What to build:** 老师自助只申请代课，提交后进入「待审批」；超级或教务管理员都能批准、改人后批准、驳回（必填理由），先处理者为准；老师审批前可撤回；开课后仍未处理自动作废。工作台直接生效保持不变。见 spec「调代审批（恢复）」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 迁移加回审批人、审批时间、审批意见（新迁移，不改 V55；续号规则同 01）
- [ ] 提交：保留现有当场检查（学期、星期、开课截止、代课人撞课、同实例唯一待审批），停在「已提交」不生效
- [ ] 批准：以「已提交」为条件更新；学期锁下按当前课表重新检查与开课截止；通过后走现有代课生效路径（含再次调整旧行退出）；写状态历史
- [ ] 改人后批准：新代课人同样当场检查；分别记录期望与最终代课人
- [ ] 驳回：理由必填
- [ ] 撤回：仅申请人、仅「已提交」
- [ ] 作废：开课后仍「已提交」→「已作废」；审批接口拒绝已过开课时刻的申请（惰性或定时清扫二选一，写入实现说明）
- [ ] 管理端「待审批」列表；老师「我的调代」显示五种状态与驳回理由
- [ ] 老师端提交表单去掉调课选项，原因框提示「想调课请写明，由教务处理」
- [ ] 集成测试：撞课被拒、撤回、改人批准、并发审批后到者被拒、驳回、开课后作废、工作台直接生效不受影响
- [ ] 新 ADR：推翻票 15 Q5「删除审批链」，不恢复 ADR-0009 的模式切换
