# 05: 恢复代课审批（待审批 / 批准 / 改人 / 驳回 / 撤回 / 作废）

**What to build:** 老师自助只申请代课，提交后进入「待审批」；超级或教务管理员都能批准、改人后批准、驳回（必填理由），先处理者为准；老师审批前可撤回；开课后仍未处理自动作废。工作台直接生效保持不变。见 spec「调代审批（恢复）」。

**Blocked by:** 01

**Status:** implemented

- [x] 提交：保留现有当场检查（学期、星期、开课截止、代课人撞课、同实例唯一待审批），停在「已提交」不生效
- [x] 批准：以「已提交」为条件更新；学期锁下按当前课表重新检查与开课截止；通过后走现有代课生效路径（含再次调整旧行退出）；写状态历史
- [x] 改人后批准：新代课人同样当场检查；分别记录期望与最终代课人
