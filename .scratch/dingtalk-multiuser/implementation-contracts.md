# 跨票实现约束

日期：2026-11-11。规格授权内的工程约束，若具体实现发现更好的方案由统筹复核后更新；不得以本文件扩展产品范围。

## 权限与角色（01）

- `super_admin` 为超级管理员；`admin` 保留编码但变为教务管理员；`teacher` 为老师。旧 admin 角色持有者迁为 super_admin 保留旧授权，不仅处理 username=admin。
- 迁移完成后启动种子只初始化角色权限，不再每次把教务管理员提升成超级管理员。
- 降级与停用共用同一个并发保护锚点。必须在读取、校验和变更最后一个启用超管之前串行化；不能先修改 managed entity 再执行会自动 flush 的锁查询。
- 设置读写按字段权限隔离：GET、PUT 的返回与 logo 上传返回都要防止教务拿到钉钉字段；无集成配置权限的混合更新在任何写入之前整体拒绝。

## 审计（02）

- 复用 audit_log，账号动作有稳定的目标账号 ID 和 before/after allowlist，支持数据库层过滤与分页；不在内存读取全表后分页。
- before/after 只含身份、启用状态、关联教师等审计必要字段。任何密码、hash、钉钉密钥、token 均不得进入日志/响应/审计。
- 操作与审计同一事务；失败回滚不能留下成功审计。批量导入要可追溯到目标账号。
- 自动开号与配对由03调用此处统一服务；同步停用由04调用。审计读取只给账号审计查看权限。

## 自动开号（03）

- 网络交换 authCode、读取姓名在事务外；教师配对、账号创建、两条审计在同一短事务。
- 不能只做查重后插入：必须有跨请求/跨实例有效的数据库串行化或唯一约束保护。重试已绑定的同一身份返回同一账号。
- 同名配对只对未绑定、未删除的合格教师候选；唯一判定必须在竞争下复核，不允许覆盖另一个钉钉身份的绑定。已停用账号不得因免登再创建替代账号或自动启用。
- 钉钉账号明确无密码，密码登录与重置密码都拒绝；提升管理员不改变其登录方式。原有密码账号保留可用。
- 结构化登录原因码不携带第三方响应原文中的秘密，不再静默转到密码页。

## 同步停用（04）

- 预演严格只读；仅针对绑定钉钉、有启用账号且本次完整目录中缺失的人员，停用账号不删除教师、不改课表。
- 不完整扫描绝不能计算或执行缺失停用；确认时必须重新验证扫描完整性和管理员选中的候选集合。
- 明确传递停用选择/排除：目录在预演与确认间变化不能扩展成用户未确认的一批停用。
- 停用经01统一保护，不能关闭最后一个超管；原JWT在下一次请求被拒绝。

## 代课审批（05）

- 复用当前 SUBMITTED 表示待审批，不新造与历史状态重复的 PENDING_APPROVAL。
- 老师提交保存申请与状态历史，不写 substitution 生效行、不发接课通知；设置 operator_user_id 为实际账号，作为撤回与通知申请人的可靠身份。
- 同一实例唯一待批、批准/驳回/撤回竞争采用统一锁顺序（学期→申请），批准在锁内重新读当前课表和真实时钟，不信任提交时快照。
- 批准保留 expectedSubstituteTeacherId 与 finalTeacherId 的差别，重新检查启用/未删除的代课人和当前实例位置；基线撤回、已变更、截止等情况清楚拒绝，不能把过期申请重新应用到新课表。
- 作废可选择定时清扫或查询/处理时惰性判定，必须真正保存状态与历史；不要在抛异常导致整体回滚的同一事务里声称已完成作废。
- 工作台管理员直接确认继续走原路径，原置换环和再次调整行为保留。

## 通知与配置（06/07）

- 审批结果定位实际申请账号，接课通知定位最终代课人，不是期望人；同一事件同一收件人不重复。
- 调课工作台保留每位被移动老师的个人通知；停发其他旧触发路径，模板保留不删，重试和发送记录沿用。
- 测试连接使用当前表单临时参数，在内存构建独立请求，不覆盖已有配置或全局token缓存。错误统一脱敏；网络调用有连接/读取上限，不暴露未保存密钥。

## 验收（08）

- 一条假钉钉HTTP整链覆盖自动开号→老师提交→教务改人批准→通知与审计；另外测试权限矩阵、竞争不变量、截止与失败分支。
- Playwright通过真实页面完成手机老师→电脑教务→老师结果；公开API仅用于建立独立未来学期的合成数据，禁止真实生产写入。
- 迁移覆盖已有总钥匙账号、原班主任、已绑定教师、业务数据保全以及重启幂等，不以空库成功替代旧库升级。
- 所有定向回归与双轴整改结束后冻结源码，一次完整verify；未运行真实PG或真钉钉的边界明确记录。
