# 03b: AI 规则面板搬到规则页

**What to build:** 高级页下线后，把「用自然语言帮填表」的只读建议面板搬到规则页（可折叠），保留生成、建议列表、历史、审计与「加入到规则」的能力。选中的建议转换成规则卡/句子加入当前编辑中的规则，保存后仍落成现有约束条目；转换不了的条目要写明原因，不能静默丢弃。后端接口、模型调用与审计不动。

**Blocked by:** 03（页面腾出位置）、02（句子模型支持全局默认范围）

**Status:** ready-for-agent

- [ ] 规则页出现 AI 建议面板；AI 未配置/关闭时显示原因，而不是报错或隐藏能力
- [ ] 生成、取消等待、历史、审计、只读提示与高级页原有行为一致
- [ ] 选中的建议能转换成规则卡并显示正确句子；同一张卡最多 3 句的上限仍生效
- [ ] 建议落到 `constraint_entry` 后与直接手写同样规则的结果一致（同一组参数、同一强度）
- [ ] 转换不了的参数组合（若仍存在）显示具体原因，不写入、不静默丢弃
- [ ] 规则页保存时沿用现有版本冲突与审计链路，不新建写入通道
- [ ] 前端单测覆盖「建议 → 规则卡」的纯函数转换；E2E 覆盖一条生成并加入的主路径（AI 可 mock 或走既有测试替身）
- [ ] `ConstraintsView` 删除后不再有对 `ConstraintAiPanel` 旧 props/工作区状态的依赖

**Notes:** 产品所有者 2026-11-07 决定保留 AI 面板并搬到规则页。协作提醒/跨设备工作区状态属于高级页草稿的旧机制，随高级页删除；AI 面板自身的历史与审计保留。
