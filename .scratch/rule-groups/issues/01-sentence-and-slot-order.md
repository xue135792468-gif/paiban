# 01: 规则读成一句话 + 拼装顺序改为 谁→课→时→要求

**What to build:** 规则页上每条规则都按主谓宾显示（如「王老师 周五下午 不上课」「体育 不在最后一节」）；新建/编辑规则时槽位顺序为 谁 → 什么课 → 什么时候 → 怎么样，边选边看到句子成形；强度只显示「必须 / 尽量」两档，不显示分量数字。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 16 类积木规则的句子都按「主语 + 时间 + 要求」生成，不出现「的 课 在」之类虚词
- [ ] 节次能折成上午/下午时显示「上午/下午」，否则显示「第 x、y 节」
- [ ] 表单槽位顺序为 谁 → 什么课 → 什么时候 → 要求；缺槽位时提示还差什么
- [ ] 选择过程中句子实时更新
- [ ] 强度只有「必须 / 尽量」，界面不出现分量数字
- [ ] 保存结果与改版前同一组选择编译出的约束条目一致（快照不变）
- [ ] 句子渲染有纯函数单测，覆盖 16 类
