# 03: ADR-0017 性能基准

**What to build:** ADR-0017 定了五条性能指标，但仓库里没有任何验证手段。加一个手动基准测试：按 ADR 的学校规模（100 班 / 500 教师 / 200 教室 / 5 天 × 8 节）生成数据，用引擎跑到零硬冲突并计时，再把结果写成课表基线，测量拖拽校验、班级/教师/教室视图、全校总表与 50 并发的响应时间。默认不跑（`-Dperf=true` 开启），结果作为验收记录写进 README。

**Blocked by:** 无

**Status:** ready-for-agent

- [x] `PerformanceBenchmarkIT`，`@EnabledIfSystemProperty(named = "perf", matches = "true")`
- [x] 数据规模与 ADR-0017 一致：100 班、500 教师、200 教室、40 个时段
- [x] 排课：测到零硬冲突的耗时，断言 < 5 分钟
- [x] 拖拽校验：取中位数，断言 < 500ms
- [x] 班级/教师/教室视图：取中位数，断言 < 200ms
- [x] 全校总表：断言 < 2s
- [x] 50 并发班级视图：全部成功且总耗时在合理范围
- [x] 输出一张可复制的指标表，README 记录实测值
