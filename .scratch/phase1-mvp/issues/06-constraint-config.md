# 06: 约束配置与预置约束库

**What to build:** 实现约束配置体系：20-30 条预置约束的枚举定义（覆盖硬约束如"教师不冲突""教室不冲突"，软约束如"体育不在下午第一节""同一教师一天最多 N 节"），约束配置表（约束类型 + 参数 JSON + 权重 + 启用状态 + 学期），约束配置 UI（勾选启用 + 参数填写 + 权重滑块），约束模板保存与加载。完成后，admin 能为当前学期启用若干约束、配置参数与权重、保存为模板以便复用。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 预置约束枚举定义（Java enum），至少覆盖：教师不冲突、教室不冲突、班级不冲突、体育不在下午第一节、同一教师一天最多 N 节、同一课程一天最多 N 节、教师禁排时段、课程必须使用特定类型教室、连堂课连排、教师偏好时段、教研组活动时段禁排等 20-30 条
- [ ] constraint_config 表（id、学期、约束类型、参数 JSON、权重、启用状态）
- [ ] UI：约束列表页（按类别分组）+ 每条约束的启用开关 + 参数表单 + 权重滑块（0-100）+ 硬/软约束切换
- [ ] UI：约束模板保存（命名）与加载
- [ ] REST API：约束配置的 CRUD + 模板保存/加载
- [ ] 参数 JSON 的 schema 校验（每条约束有自己的参数 schema，如"同一教师一天最多 N 节"的 N）
- [ ] REST Assured 集成测试：创建约束配置 → 保存为模板 → 加载模板到新学期
