# 04: 年级/班级/教师/教室/课程基础数据 + Excel 导入

**What to build:** 实现五类基础数据的完整管理：年级（Grade）、行政班（AdminClass）、教师（Teacher）、教室（Room）、课程（Course），每类都支持 CRUD UI + Excel 批量导入（含 dry-run 错误预览）+ Excel 导出。完成后，admin 能从 Excel 一键导入 50 个教师、10 个班级、20 间教室，看到导入预览与错误行报告，确认后才入库。

**Blocked by:** 03

**Status:** done

- [ ] 五张表的数据库迁移脚本，字段遵循 GLOSSARY 与 ADR-0011（年级/班级按学期隔离，教师/教室/课程全局）
- [ ] 行政班表与教学班表分离（ADR-0001），一期 UI 上行政班与教学班一对一自动创建
- [ ] 每类实体的 CRUD REST API + Vue 列表页与编辑页
- [ ] 每类实体的 Excel 模板下载、上传导入、dry-run 错误预览、确认入库两步流程
- [ ] 导入错误报告：行号、字段、错误原因，可导出为 Excel 供修正后重新导入
- [ ] Excel 导入接缝测试：正确样本、缺列、多余列、合并单元格、中文表头、超长字段、公式等边界样本
- [ ] 所有导入操作记录审计日志（谁、何时、导入了什么、成功/失败行数）
- [ ] 教室支持类型字段（普通教室/实验室/操场等），课程支持元数据（是否允许连堂、是否必须室外场地等）
