# 03: 学期与作息表

**What to build:** 实现学期管理与作息表配置：学期 CRUD、设置"当前学期"（全局唯一）、作息表配置（每天几节课、每节课时长、午休时段、晚自习）。完成后，admin 能创建"2025 秋季学期"并配好"上午 4 节下午 4 节晚自习 2 节"的作息，后续所有排课数据都关联到这个学期。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 学期表（id、名称、开始日期、结束日期、是否当前学期）
- [ ] 设置当前学期接口：全局只有一个当前学期，切换时把旧的取消
- [ ] 作息表表（关联学期，每天的节次配置：上午/下午/晚自习各几节，每节起止时间）
- [ ] admin UI：学期列表页 + 新建/编辑学期 + 配置作息表
- [ ] admin UI：可视化编辑作息表（表格形式，行是时段，列是周一到周日）
- [ ] REST Assured 集成测试：创建学期 → 配置作息表 → 设置当前学期 → 查询当前学期的作息
- [ ] 遵循 ADR-0011（学期数据隔离）：学期表本身全局，作息表关联学期
