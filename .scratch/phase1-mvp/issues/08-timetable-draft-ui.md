# 08: 课表草稿 UI（网格 + 拖拽 + 实时冲突校验）

**What to build:** 实现课表草稿的可视化编辑：CSS Grid 自研课表矩阵（上午/下午/晚自习分区、行是节次、列是周一到周日）、拖拽移动课节、毫秒级增量冲突校验、冲突原因浮窗、未排课时抽屉、多草稿管理（保存/重命名/切换/删除）。完成后，admin 打开排课结果草稿，能拖拽"张老师周一第 1 节"到周二第 3 节，系统立刻提示冲突并以红色高亮不可用位置、绿色高亮可用位置；未排课时显示在右侧抽屉，可直接拖入网格。

**Blocked by:** 07

**Status:** done

- [ ] CSS Grid 课表矩阵：行是节次（按作息表渲染），列是周一到周日（可扩展），单元格显示课程名 + 教师 + 教室
- [ ] 支持班级视角 / 教师视角 / 教室视角切换
- [ ] 拖拽：基于 vue-draggable 或 @hello-pangea/dnd 实现课节跨单元格移动
- [ ] 拖拽过程中实时调用 07 票的增量校验接口，可用时段绿色高亮、冲突时段红色高亮
- [ ] 冲突原因浮窗：hover 红色单元格显示具体原因（如"张老师此时在 3 班有数学课"）
- [ ] 未排课时抽屉：右侧折叠面板，显示当前草稿中尚未分配的授课任务，可拖入网格
- [ ] 多草稿管理：保存当前草稿、重命名、切换草稿、删除草稿、并排比较两个草稿
- [ ] 当前草稿的冲突总数与得分显示在页面顶部
- [ ] Playwright E2E 测试：拖拽课节到冲突位置看到红色提示，拖到空位成功
- [ ] 马卡龙学科色谱：不同课程用不同低饱和度颜色区分（调研报告中的 UI 参考）
