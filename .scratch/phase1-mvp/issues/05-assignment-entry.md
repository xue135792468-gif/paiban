# 05: 授课任务录入

**What to build:** 实现授课任务（Assignment）的录入与管理：支持"某行政班 + 某课程 + 每周 N 节 + 任课教师"的录入（单条与 Excel 批量），按班级/教师/课程三个维度筛选查看。完成后，admin 能录入"高一 1 班数学每周 5 节张老师"，并在"张老师的授课任务"视图看到这条记录。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Assignment 表（关联学期、行政班/教学班、课程、教师、每周节数）
- [ ] 录入授课任务时校验：班级、课程、教师都存在且属于当前学期
- [ ] UI：单条录入表单 + 列表页（按班级/教师/课程筛选）
- [ ] UI：批量 Excel 导入（模板包含：班级名、课程名、教师姓名、每周节数）
- [ ] UI：教师视角的"我的授课任务"列表（teacher 角色也能访问，用于核对自己的任务）
- [ ] REST Assured 集成测试：录入 → 筛选 → Excel 导入 → 校验权限（teacher 只能看自己的）
- [ ] 数据准备：此票完成后应能用 SQL 或 Excel 批量导入构造出 3 个班 10 个授课任务的测试数据集
