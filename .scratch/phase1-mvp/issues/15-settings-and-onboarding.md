# 15: 设置中心与初始化向导

**What to build:** 实现设置中心与初始化向导：设置页汇总所有可配置项（调代审批模式、通知范围、钉钉开关与凭证、AI 特性占位开关、学校信息、Logo 上传）；初始化向导（首次登录推荐，可跳过，6-8 步分步引导：学校信息 → 作息表 → 年级班级 → 教师 → 教室 → 课程 → 授课任务 → 约束规则），每步支持 Excel 导入，向导进度持久化可跨会话恢复。完成后，新 admin 首次登录看到向导引导，依次完成各环节；老账号登录直接进主界面。

**Blocked by:** 13, 14

**Status:** ready-for-agent

- [ ] 设置中心页：分组展示所有配置项（审批模式、通知范围、钉钉、AI 特性占位、学校信息、Logo）
- [ ] 所有 ADR 中提到的配置项都可在 UI 修改并立即生效（无需重启）
- [ ] AI 特性开关占位：显示"即将推出"的 disabled 开关（ADR-0003）
- [ ] 学校 Logo 上传（用于 PDF 导出）
- [ ] 初始化向导：6-8 步分步引导，每步对应一种基础数据的录入或 Excel 导入
- [ ] 向导进度持久化：onboarding_progress 表（用户、当前步骤、已完成步骤、数据 JSON），可跨会话恢复
- [ ] 向导可跳过，跳过后不再主动弹出（设置里可重新进入）
- [ ] 主界面在数据不完整时给出"还差什么"的引导提示（如"还未配置作息表，点击前往"），但不阻止访问
- [ ] 老用户（已有数据的）登录直接进主界面，不弹向导
- [ ] Playwright E2E 测试（验收场景 1 完整走通）：首次登录 → 向导引导 → 完成初始化 → 排课 → 发布
- [ ] REST Assured 集成测试：设置修改 → 生效验证；向导进度保存与恢复
