# 草案 02: 停止保留结果、放弃使会话终止

**What to build:** 用户在整本解析时能停止后续调用并查看已完成范围，或放弃整个导入；旧请求晚返回不会恢复可提交状态。
**Blocked by:** 01
**Status:** ready-for-agent
**Execution:** 2026-10-26 复核通过，可开工
**Spec:** ../spec.md

- [ ] 页面与接口均提供停止/放弃，按会话权限校验；停止在批次边界生效，不声称撤回供应商已收到的调用。
- [ ] 停止保留已完成结果并列未覆盖范围；放弃不写业务主数据且不可继续提交。
- [ ] 晚响应只落审计，不覆盖停止/放弃或新运行；重复请求幂等。
- [ ] 停止后仍有未覆盖范围时禁止部分入库，沿用八期边界。
- [ ] 可阻塞假网关验证停止/晚返回、放弃/晚返回、重复点击及权限；页面结果与持久化一致。
- [ ] 先红后绿，独立评审与完整闸门。

**范围边界：** 不做 HTTP 请求物理取消，不默认提交已成功的一部分课表。

**复核记录：** 批次启动复核通过（2026-10-26）：状态机已含 `PARTIAL`/`ABANDONED`，停止与放弃可在其上扩展。
