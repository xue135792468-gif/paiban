# 草案 01: 整本解析在后台运行并可恢复进度

**What to build:** 上传后即可获得会话，页面展示规划/取值阶段和逐批进度，刷新后仍能看到已完成结果。
**Blocked by:** None
**Status:** draft
**Execution:** 下一批；本轮不实施
**Spec:** ../spec.md

- [ ] 工具规划与取值在导入线程串行执行；规划阶段不显示伪造的批次数。
- [ ] 稳定计划包含工作表、范围和结构版本；批次原文、结果和计数及时持久化。
- [ ] 规划阶段失败且无确认计划时，页面提供显式重新规划入口；已有计划的恢复不自动重跑工具规划。
- [ ] 单批失败后仍处理其他批次，结果可查看，失败/未完成范围存在时前后端均不可提交。
- [ ] 刷新、重启、执行器拒绝、存储失败有可恢复且可观察的状态；解析不写业务主数据。
- [ ] REST＋受控假网关观察中间进度，Playwright 覆盖刷新恢复；旧单目标流程保持兼容。
- [ ] 先红后绿，独立评审与完整闸门；下一批启动前复核规格及当前代码。

**交付范围：** 一条完整上传→后台→轮询→预览路径，不按“只做数据库/只做前端”拆分。
