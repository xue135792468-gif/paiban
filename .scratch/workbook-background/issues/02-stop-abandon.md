# 票据 02: 停止保留结果、放弃使会话终止

**What to build:** 用户在整本解析时能停止后续调用并查看已完成范围，或放弃整个导入；旧请求晚返回不会恢复可提交状态。
**Blocked by:** 01
**Status:** done
**Execution:** 已实现（2026-10-26，`feature/workbook-background-import`）
**Spec:** ../spec.md

- [x] 页面与接口均提供停止/放弃，按会话权限校验；停止在批次边界生效，不声称撤回供应商已收到的调用。
- [x] 停止保留已完成结果并列未覆盖范围；放弃不写业务主数据且不可继续提交。
- [x] 晚响应只落审计，不覆盖停止/放弃或新运行；重复请求幂等。
- [x] 停止后仍有未覆盖范围时禁止部分入库，沿用八期边界。
- [x] 可阻塞假网关验证停止/晚返回、放弃/晚返回、重复点击及权限；页面结果与持久化一致。
- [x] 先红后绿，独立评审与完整闸门。

**范围边界：** 不做 HTTP 请求物理取消，不默认提交已成功的一部分课表。

**复核记录：** 批次启动复核通过（2026-10-26）：状态机已含 `PARTIAL`/`ABANDONED`，停止与放弃可在其上扩展。

**实现说明：** `AiImportService.stop/abandon` 对 workbook 会话转交 `WorkbookImportFlow`；新增 `run_id` 作为运行身份。停止把 `PENDING` 批次标为 `FAILED`（「这一批的结果未采用」）而不是删除，已完成范围保留，未覆盖范围可重试；没有确认计划（仍在规划阶段）时 `FAILED`，有计划时即使 0 个批次完成也收尾 `PARTIAL`，可只重试未覆盖范围。晚返回只把原始回答追加到批次审计与 `ai_raw_response`，不改状态或预览。放弃把会话置 `ABANDONED` 并清空运行身份。测试覆盖停止保留、重复停止 409、放弃后晚响应、停止后重试。
