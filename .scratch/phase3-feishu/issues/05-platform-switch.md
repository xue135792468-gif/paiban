# 05: 平台一键切换与数据迁移

**What to build:** 实现钉钉 ↔ 飞书一键切换：设置页选择当前启用平台、切换时保留所有本地数据、教师首次新平台登录时自助绑定身份、历史通知记录保留并标记来源。完成后，学校从钉钉迁移到飞书时，教务管理员一键切换，教师第一次用飞书登录时输入工号完成绑定，所有历史数据完好保留。

**Blocked by:** 02, 03, 04

**Status:** done

- [x] `system_config` 新增 `integration.active_platform`（枚举：none / dingtalk / feishu）
- [x] 设置页"IM 平台"卡片：单选按钮（不启用 / 钉钉 / 飞书）、状态显示、配置入口、切换按钮
- [x] 一键切换逻辑：停用原平台 → 启用新平台 → 触发组织同步 → 通知渠道切换 → 记录切换日志
- [x] 切换确认提示："将停用钉钉，启用飞书。教职工数据保留，需重新绑定飞书账号。"
- [x] 教师自助绑定页面：首次新平台登录时，输入工号 / 手机号 / 姓名+身份证号后四位验证身份
- [x] 绑定逻辑：匹配本地教师表，更新 feishu_user_id（切回钉钉后由教务在教师管理页维护 dingtalk_user_id）
- [x] 绑定失败处理：提示"未找到您的信息，请联系教务管理员"
- [x] 教务管理界面：教师列表显示平台绑定状态（钉钉/飞书/未绑定），支持手动修改绑定
- [x] 历史数据保留：切换后原平台的所有数据（通知记录、审批历史）保留并标记来源
- [x] 单元测试：切换逻辑、绑定逻辑、冲突处理
- [x] E2E 测试：完整切换流程（钉钉 → 飞书 → 教师绑定 → 功能验证）
