# 02: 飞书 H5 微应用与免登

**What to build:** 实现飞书 H5 微应用形态与免登流程：前端检测飞书环境、调用飞书 JSAPI 获取授权码、后端换取用户信息、颁发系统 JWT。完成后，教师从飞书工作台点击应用图标直接进入系统，无需输入账号密码。

**Blocked by:** 01

**Status:** done

- [x] 前端环境检测：`window.tt` 对象存在则判定为飞书环境
- [x] 飞书 JSAPI 接入：`window.tt.requestAccess` 获取授权码
- [x] 后端免登接口：POST `/api/auth/feishu`，接收授权码，调用飞书 API 换取用户信息，颁发 JWT
- [x] 前端自动登录：飞书环境下自动调用免登接口，失败时降级到账号密码登录
- [x] 浏览器与飞书双形态：同一套前端代码，浏览器访问走本地登录，飞书内访问走免登
- [x] 飞书工作台应用配置文档：README 中添加飞书应用创建与配置步骤
- [x] 单元测试：模拟飞书环境检测与免登流程（由 Playwright E2E 覆盖；仓库无前端单测运行器）
- [x] E2E 测试：Playwright 模拟飞书环境（注入 `window.tt` mock），验证免登流程
