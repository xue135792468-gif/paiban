# 04: 跨天搜索与可配置策略

**What to build:** 调课搜索从「同一天」扩展到可配置的自然日窗口：默认 7 天、最大 30 天。周五的课在当天无解时，能搜到下周一至周四；跨天方案按影响天数优先、同周优先、影响教师数、软约束扣分排序。教师数上限默认 6、可配置为 2–10；排序支持三个预设（最小影响 / 最少教师 / 最稳课表），教务在设置页切换，方案卡显示当前排序标签。

**Blocked by:** 03

**Status:** done

- [x] 搜索窗口默认 7 天、可在 1–30 之间配置，设置即时生效
- [x] 周五的课能生成跨到下周一至周四的方案；超出窗口判无解
- [x] 跨天方案按「影响天数 → 同周优先 → 影响教师数 → 软约束扣分」排序
- [x] 教师数上限默认 6、可配 2–10；超过上限的环不生成
- [x] 三个排序预设可切换，默认「最小影响」；方案卡显示当前排序；切换后新生成的方案按新排序
- [x] 跨天环天然保持每个涉及日期的班级节数不变，校验器复核通过
- [x] 单元测试覆盖跨天 2/3 人环、周五跨下周、窗口边界、教师数上限、三个预设的排序差异

**实现说明：** 设置项 `substitution.search-window-days`（1–30，默认 7）、`substitution.max-plan-teachers`（2–10，默认 6）、`substitution.ranking-preset`（默认 min-impact），即时生效并在设置页/帮助中心说明。跨天由「日期+节次」节点图天然支持，`min-impact` 严格同日优先，另外两个预设按各自首要标准跨层比较。测试：跨天 3 人环、周五→下周一至周四、窗口边界、教师上限、预设排序差异；Playwright 场景 9b 覆盖跨天整单批准。
