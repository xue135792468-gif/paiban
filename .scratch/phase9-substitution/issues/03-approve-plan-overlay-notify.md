# 03: 整单批准、课表叠加与通知

**What to build:** 教务整单批准一个调课方案：系统在一个事务里写入全部课节移动、更新申请状态、发通知。课表「最新」视角把相关课节标成「调」，原始视角不变。方案带生成时的课表快照哈希和 30 分钟有效期；批准时如果课表已变化或结构校验失败，整单拒绝，绝不允许部分生效。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 批准在一个事务内完成：写 N 行 `substitution`（`type=SWAP`）、更新请求为 `EFFECTIVE`、写审计记录、发通知；任一步失败全部回滚
- [ ] 课表「最新」视角显示「调」标记，悬停可看原教师、原因、生效日期；「原始」视角完全不变
- [ ] 所有被卷入教师（去重）、该班班主任、教务收到通知；范围沿用现有 `notification.scope` 设置
- [ ] 方案携带快照哈希与 30 分钟过期；批准时哈希变化或结构校验失败 → 返回 409 与违规清单，整单不生效、零写入
- [ ] 最小结构校验器：只有方案内课节发生变化；教师/班级/教室同刻唯一；班级每天节数不变
- [ ] 集成测试覆盖 2 人方案与 3 人方案批准后的课表、通知、记录；并发冲突下零写入
