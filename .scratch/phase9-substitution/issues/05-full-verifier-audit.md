# 05: 完整约束校验器与审计告警

**What to build:** 把批准前的校验从「最小结构检查」升级为完整校验：覆盖全部 24 类硬约束、独立重算软约束扣分、确认方案外课节零变动、确认每节课的课程与教师未被误改（代课除外）。任何违规都整单拒绝，写审计日志并发告警。校验器与求解器彼此独立，求解器出错也不能让坏方案落库。

**Blocked by:** 03

**Status:** done

- [x] 独立实现四条核心不变量（同一教师同刻唯一、同一班级同刻唯一、同一教室同刻唯一、班级每天节数不变），不与求解器共用 helper
- [x] 24 类硬约束全部覆盖；软约束扣分独立重算，与求解器报告值不一致时判失败
- [x] 方案外课节被修改、课程/教师被误改（代课除外）都拒绝
- [x] 失败返回逐条违规清单（约束码、课节、涉及教师/班级/教室），写审计日志并告警，不产生任何 `substitution` 行
- [x] 属性测试：随机生成合法课表与方案 → 校验器必须通过；随机篡改一条移动 → 校验器必须拒绝；固定种子，至少 200 组
- [x] 性能：一学期约 2000 条课表记录的全量校验低于 100ms

**实现说明：** `PlanVerifier` 独立实现四条不变量（教师/班级/教室同刻唯一、班级每天节数不变），不调用求解器 helper；硬规则覆盖 24 类（默认软的 10 类在标为 hard 时也会拒绝），并检查方案外零变动、课程/教师不变、软分重算一致。失败路径用 `SubstitutionAuditService` 的 REQUIRES_NEW 事务写审计与告警，主事务回滚不影响留痕。测试：200 组固定种子属性测试（方案必过、单条篡改必拒）、教师/班级/教室/节数/软分专项、2000 条课表校验 <100ms。
