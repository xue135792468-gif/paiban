# 06: 代课接入与统计分离

**What to build:** 代课与调课共用同一个入口，但走现有单向补位流程：教师提交代课（日期、课节、期望代课教师、原因），教务批准或按「直接生效」模式自动生效；批准前同样跑校验器。记录页与导出区分「调课」和「代课」；统计里「代课次数」只统计代课，调课单独统计「参与调课次数」，课时量按净变化计算。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 代课申请写 `type=COVER`，沿用现有审批模式与直接生效模式；切换设置只影响新申请
- [ ] 代课批准前跑校验器，失败整单拒绝并返回违规清单
- [ ] 前端「我的调代」类型切换支持代课；表单与现有字段一致
- [ ] 调代记录与导出显示类型标签；调课记录可展开该方案的全部移动
- [ ] 统计接口分别返回被代课次数、代课次数（仅 COVER）、参与调课次数；一笔 3 人调课不增加任何人的代课次数
- [ ] 集成测试覆盖代课现有流程回归、直接生效模式、统计口径
