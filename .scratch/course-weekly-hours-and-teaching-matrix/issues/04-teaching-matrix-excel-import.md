# 04: 任课表二维矩阵 Excel 预览、补课时与原子导入

**What to build:** 让教务管理员在「任课表」页面选定目标学期与年级后，直接上传学校现成的二维任课表 Excel（含「班级、人数、班主任」与若干学科列，兼容表头上方标题行及表头空格/换行），作为新学期开局建档或开学前换师重导的数据源。导入走「只读预演 → 单事务原子提交」两阶段流程：预演阶段展示将自动补建或匹配的班级、教师、课程清单，每条授课任务的动作（新建 / 改老师 / 不变），班级周总课时容量预警，以及同名教师或非法人数等阻断错误；对缺少周课时数或需要按本年级微调的课程，用户可在预览弹窗中直接填写每周节数（并可勾选同步回写为课程默认周课时）；确认提交后在单个事务内原子落库，一并写入或更新行政班人数与班主任（自动触发班主任规则分组同步），重复导入幂等且只增改表内涉及学科、绝不误删未列出的其他学科，空格跳过。

**Blocked by:** 01: 课程管理支持可选「周课时数」、02: 班主任自动规则分组（全校「班主任」+ 分年级「{年级名}班主任」）、03: 数据管理「任课表」二维方阵页面与点格编辑 / 删除撤销

**Status:** done

- [x] 矩阵解析器能跳过表头上方标题行、识别清洗空格与换行后的「班级」（必填）、「人数」（选填）、「班主任」（选填）及动态学科列；同年级内先按班名精确匹配、再按班号数字唯一匹配，多班命中报错阻断，未命中则在空学期/缺班场景规划按「年级名（班号）班」新建。
- [x] 预演接口严格只读（零数据库写入），返回新建/匹配实体汇总（班级、教师、课程）、缺少周课时或可覆盖周课时的课程列表、行级预览动作（新建 / 改老师 / 不变）、错误清单与班级总周课时超可用节次预警。
- [x] 预览弹窗支持为缺周课时的课程行内补填 1–20 整数，也支持对已有默认周课时的课程做本次导入临时覆盖，并提供勾选「同步保存为课程默认周课时」；若仍有待新建授课任务的课程未提供周课时，阻止提交并高亮提示。
- [x] 遇到同名教师（库中存在多名同名教师）、非法学生人数、重复班级行、非当前学期年级或回收站软删除任务冲突时，预演标出具体行号与原因，提交全批拒绝、零写入，并记录审计日志。
- [x] 确认提交在单事务内按顺序原子落库（新建缺失教师与课程 → 新建或更新行政班含人数与班主任 → 幂等 Upsert 表内非空学科的授课任务 → 记录导入审计），并自动触发全校「班主任」与「{年级名}班主任」分组同步。
- [x] 重复导入同一份或修改后的部分学科矩阵时：空单元格跳过，表内未出现的其他学科授课任务（如体育、托管）保持完好不被删除，无变动格子不重复写库。
- [x] 后端解析器单测、矩阵导入集成测试（含事务回滚、权限控制与班主任分组联动）及前端导入弹窗单测全部通过。

预演与提交共用解析和计划逻辑，提交在事务内重新校验。保留每班已有节数，只有填写课程覆盖值才更新表内已有任务的节数。集成测试验证预演零写入、无效行整批拒绝并审计、提交写入中途失败回滚、部分表格重导及班主任分组联动。
