# 03: 数据管理「任课表」二维方阵页面与点格编辑 / 删除撤销

**What to build:** 在「数据管理」导航中新增「任课表」二级页签，让教务管理员按「学期 + 年级」在一张「行政班 × 课程」二维大表格中直观查看和维护全年级授课任务（与「授课任务」共用同一份底层数据，不新建独立数据表）。表格左侧固定显示行政班、学生人数与班主任，课程列头显示课程默认周课时数，个别班与课程默认节数不一致的格子给出清晰标记；点击空白格可直接选老师并自动带出课程默认周课时新建授课任务，点击已有格可更换任课教师或微调每周节数，也可点击「删除」经二次确认（展示删除影响）软删除该任务，并在页面立即给出「撤销」操作条一键还原（同时保留在 7 天回收站中）；新建时如撞上回收站中已软删除的同班同课任务，返回清晰可读的引导提示。

**Blocked by:** 01: 课程管理支持可选「周课时数」

**Status:** done

- [x] 「数据管理」二级导航中对具备授课任务管理权限的账号展示「任课表」页签，可切换学期与年级，按班级顺序与课程顺序渲染二维方阵，并展示每班人数、班主任及课程列头默认周课时数。
- [x] 某行政班某门课程的实际每周节数与课程默认周课时不同时，对应单元格清晰标出实际节数，方便教务一眼识别特殊班。
- [x] 点击空白格可选择启用的任课教师，自动带入该课程的默认周课时数（支持当场改填 1–20），保存后直接写入授课任务并刷新方阵；点击已有格可更换教师或修改每周节数，保存后立即在「授课任务」页与自动排课中生效。
- [x] 新建或更新授课任务碰撞到回收站中已软删除的同班同课记录时，接口返回明确的 409 可读提示（说明该任务在回收站中，引导去恢复或等待清理）。
- [x] 点击已有格中的「删除」先弹出二次确认影响对话框；确认后该格变空，且页面立即展示带「撤销」按钮的提示条，点击「撤销」即可原地恢复该格任务；关闭提示后 7 天内仍可在「设置 → 最近删除」中恢复。
- [x] 不修改已超体积上限的既有「授课任务」列表主页面；方阵构建纯函数单测、页面组件单测、后端集成测试及前端 lint/build/SFC 体积门禁全部通过。

## 交付记录

任课表使用既有授课任务、删除影响和批次恢复接口。V66 让回收期结束的授课任务释放同班同课的占位，同时保留旧任务 ID 供历史草稿引用。真实 PostgreSQL 浏览器用例验证了点格删除及即时撤销。
