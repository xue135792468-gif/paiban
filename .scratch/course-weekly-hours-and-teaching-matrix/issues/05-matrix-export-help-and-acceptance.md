# 05: 任课表模板下载、导出与端到端整体验收

**What to build:** 为「任课表」页面补齐按当前学期与年级一键下载空白任课表 Excel 模板和导出当前年级任课表 Excel 的能力（格式与导入完全对齐，包含班级、人数、班主任与各学科列，方便发给年级组长核对后再导回），同步补全帮助中心文档；用一条覆盖真实用户开局全链路的 Playwright 端到端用例验收整套特性，更新项目本地验证技能映射，并通过全量质量门禁。

**Blocked by:** 04: 任课表二维矩阵 Excel 预览、补课时与原子导入

**Status:** in-progress

- [ ] 在「任课表」页点击「下载模板」可下载以当前年级班级预填好「班级、人数、班主任」及课程表头的 Excel 模板；点击「导出」可导出当前年级完整的二维任课表，且导出的文件可直接无修改重新上传通过预演（全部动作显示「不变」）。
- [ ] 帮助中心补充「课程周课时数」「任课表方阵与 Excel 导入导出」及「班主任自动规则分组」的用户操作说明。
