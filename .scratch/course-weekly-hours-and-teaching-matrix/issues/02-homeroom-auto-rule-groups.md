# 02: 班主任自动规则分组（全校「班主任」+ 分年级「{年级名}班主任」）

**What to build:** 让系统基于当前学期所有有效行政班的班主任信息，自动在排课规则的教师分组中维护两套开箱即用的班主任分组——全校总组「班主任」和每个有班主任的年级对应的「{年级名}班主任」分组（如「八年级班主任」）。当教务管理员在行政班页设置、修改、清空、删除/恢复带班主任的班级，或切换当前学期时，这些自动分组的成员实时同步更新，并在排课规则快照中自动展开对自动排课、草稿校验与调代校验生效；一旦用户在排课规则页手工编辑过某个自动分组，该分组即转为手动维护，后续系统不再自动覆盖。

**Blocked by:** None (can start immediately)

**Status:** in-progress

- [ ] 基础数据域与排课规则域通过中立领域事件解耦（不引入反向模块依赖，仓库模块边界检查通过）。
- [ ] 在当前学期为行政班指定、更换、清空、软删除或恢复班主任后，自动同步更新全校总组「班主任」（当前学期全部班主任去重集合）以及对应年级的「{年级名}班主任」教师分组。
- [ ] 切换当前学期时，自动维护的班主任分组自动按新当前学期的行政班班主任刷新；当前学期没有任何班主任时不强建空分组，已有且被规则引用的自动分组不被误删。
- [ ] 在排课规则页直接选用「班主任」或「{年级名}班主任」分组创建规则后，约束快照展开包含对应全部班主任，且更换某班班主任后无需重新保存规则即可对排课和校验生效。
- [ ] 用户在排课规则页手工编辑过某个班主任自动分组后，其自动填充标记被清除，后续行政班班主任变更或切换学期不再覆盖该分组的人工成员。
- [ ] 后端集成测试（含事件同步、规则快照展开、人工接管保护与切换学期）及仓库模块边界检查全部通过。
