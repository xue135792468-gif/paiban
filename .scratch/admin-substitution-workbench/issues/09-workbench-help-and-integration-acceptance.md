# 09: 工作台使用说明与集成验收

**What to build:** 在完整功能交付时补充面向使用者的帮助说明，讲清一次性日期、代课/调课、再次调整、确认截止和左右对照。汇总管理员、教师、班主任的端到端结果，执行集成门禁并整理关键页面截图、迁移准备与验收证据。逐票正确性必须已在各票自身验收；本票不替代其测试，也不构成生产切换或上线授权。

**Blocked by:** 01:按实际授课日期查看和导出一次性调代; 02:历史调代日期转换预检与兼容; 03:管理员指定代课：预览、代发与亲自确认; 04:课前更换代课人与恢复原安排; 05:管理员同班调课方案与跨日对照; 06:已发布课表拖拽进入调课预览; 07:已调课实例继续调课或代课; 08:全站导航与内容独立滚动

**Status:** in-progress (2026-10-29, branch feature/t09-workbench-help-acceptance)

- [ ] 帮助说明解释调代只作用于指定实际授课日期，不延续为每周常规安排。
- [ ] 帮助说明区分代课、同班置换调课、再次修订、恢复基线与历史版本。
- [ ] 帮助说明指出提交审批与管理员亲自确认的差别，以及管理员仍受权限和开课截止约束。
- [ ] 帮助说明左右面板代表本次调整前后，变化清单包含整份置换环及实际日期。
- [ ] 管理员 Playwright 流程验证代人申请、对照、待批/确认、再次调整和最终安排可见。
- [ ] 教师流程验证自助申请与自己当前有效授课；班主任流程验证仅能查看授权班级范围。
- [ ] HTTP 集成验收覆盖申请、审批、生效、再次修订、历史、统计、通知和导出的一致性。
- [ ] Playwright 验收覆盖拖拽/表单、全站滚动和帮助内容关键可见行为，并保存可复核截图或断言证据。
- [ ] 全部前置票的定向验收结果可追溯；集成分支按项目门禁完成全量验证，记录版本、命令与结果。
- [ ] 在真实 PostgreSQL 条件下验证迁移与历史数据确认准备；失败或未确认状态如实记录，不声称已完成切换。
- [ ] 交付记录区分代码/测试/迁移准备证据与生产发布；任何上线仍须独立授权和发布门禁。
