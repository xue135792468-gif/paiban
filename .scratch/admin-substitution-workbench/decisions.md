## 随规格草案提交确认的细化建议

这些条目是上述规则的实现边界，尚未把完整规格视为已批准：

1. 截止按学校时区 Asia/Shanghai、服务器时钟与课节开始时间判定；整单比较调整前、调整后所有被改变授课的开课时间，取最早值，等于该值即拒绝。追溯用的基线原日期不单独形成额外截止。
2. 不整单回滚以前的置换环。已开课实例被冻结，剩余实例只有在不改变它们的前提下还能形成合法新方案时才可继续调整。
3. 一次已生效安排的修改是新修订；提交审批期间旧安排继续生效，批准时原子切换；驳回、过期或失败保持旧安排。
4. 管理操作权限由已有提交、审批、全校课表查看权限组合控制；仅有查看权限不赋予写权限。管理代发及直接生效均要求审批权限，管理代发还要求提交权限。
5. 预览不创建申请、生效记录或通知；允许保存短期预览凭证。相同确认的重试只生成一份申请/修订及一组通知。
6. 确认前重验当前权限、快照、规则、设置与开课截止。旧快照、重复竞争或选定方案失效时明确拒绝并重新预览，不自动改选另一个方案。
7. “原任课教师”保留基线来源；记录另列调整前教师、调整后教师和真实操作者。A→B→C 的最终代课统计为 A 被代 1 次、C 代 1 次、B 本次代课 0 次。
8. 通知覆盖当前与新安排受影响教师的并集，告知被解除代课的 B 和新接替的 C；班主任、教务等沿用现有通知设置。历史通知保留并可定位最新修订。
9. 恢复基线作为一次经校验的再次调整，通过新修订完成；历史和已发生授课不删除。

## 当前代码事实与差距

证据只代表静态源代码调查；没有连接生产环境、调用真实业务接口或验证线上行为。

| 当前事实 | 证据与影响 |
| --- | --- |
| 后端创建已支持管理者代人提交，但以全部调代查看权限识别管理者 | `SubstitutionRequestService.create`；需收紧为操作权限，记录账号身份并保留本人教师/原教师区分。 |
| 前端只从当前账号的 teacherId 加载申请课节 | `SubstitutionRequestForm`、`SubstitutionsView`；未绑定教师的管理员无法使用表单。 |
| 同 entryId + effectiveDate 存在生效记录或未结束申请时拒绝创建 | `SubstitutionRequestService.create`；新修订需明确前版本和状态语义，不能仅删掉去重校验。 |
| 最新课表和求解快照采用截止日期前最后一笔调代持续覆盖 | `TimetableViewService.overlayMap`、`PlanSnapshot.latestPerEntry`；与已确认一次性日期语义冲突。 |
| 方案移动有 fromDate/toDate，生效行没有完整目标日期 | `SubstitutionPlanMove`、`SubstitutionEffects.createSwapSubstitution`；需要保留授课实例身份及实际目标日期。 |
| 教师课表先按基线教师筛选再叠加，未像教室视图一样最终过滤 | `TimetableViewService.teacherView`；新读模型必须按最终有效教师归属，防止已解除教师仍显示该课。 |
| 现有 SWAP 以目标星期推算最近日期，不能表达重复周槽和明确目标日期 | `SwapPlanner.Request` 与目标日期计算；新入口固定目标实际日期，老调用兼容需明确。 |
| 批准方案已有学期行锁、30 分钟 TTL、快照哈希、独立校验与整单事务 | `SubstitutionPlanService.approvePlan`、`SubstitutionEffects.lockSemester`；保留，不用 TTL 代替开课截止。 |
| 规则校验对普通硬规则做差分，核心唯一性/每天节数绝对检查 | `PlanVerifier.checkHardRules/checkInvariants`、ADR-0025 的 2026-10-26 修订；本功能不改为全课表绝对规则校验。 |
| 指定代课没有同科硬条件，推荐池同科优先 | `SubstitutionRecommendationService.candidatePool` 与批准服务；新 UI 提示跨科，最终冲突仍由后端决定。 |
| 课节已有 LocalTime startTime，未发现学校时区设置 | `Period`、`SemesterDtos`；固定 Asia/Shanghai 是本期细化建议，不是声称已有配置。 |
| 当前统计直接数生效事件行 | `SubstitutionQueryService.stats`；多次修订需避免把中间教师/旧计划重复计入。 |
| 当前布局没有视口高度约束及右侧滚动复位 | `MainLayout` 与 router；全站修复，布局票无调代数据依赖。 |
