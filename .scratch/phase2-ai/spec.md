# 排课系统二期规格：初中 AI 减负

Status: ready-for-agent

---

## Problem Statement

一期交付后，教务老师（特别是初中）反馈系统"复杂麻烦"：
1. 系统按"通用中学"设计，夹杂了高中思维（复杂约束、权重滑块、多草稿对比等），初中教务不需要这些
2. 初始化时要手工录入大量 Excel 数据，格式要求严格，学习成本高
3. 调代课时教务要自己判断"谁有空代课"，缺乏智能辅助

## Solution

二期聚焦"初中教务的 AI 减负"：

1. **初中/高中模式切换**：设置项切换学校类型，初中模式隐藏复杂功能，界面简洁
2. **AI 供应商管理**：支持多供应商多模型（DeepSeek、Gemini、自定义中转站），统一/分开任务分配
3. **AI 数据导入**：上传 Excel/文本/图片 → AI 解析 → 预览微调 → 确认入库，替代传统模板导入
4. **AI 调代推荐**：教务审批界面手动触发，AI 推荐 3 个代课人选及理由

## User Stories

### 初中/高中模式

1. 作为**教务管理员**，我希望能在设置里切换"初中模式"，以便界面只显示我需要的功能。
2. 作为**教务管理员**，我希望初中模式下约束配置简化为"必须/尽量"两档，以便不用理解权重数字。
3. 作为**教务管理员**，我希望初中模式下隐藏多草稿对比、约束模板等高级功能，以便界面清爽。
4. 作为**教务管理员**，我希望初中模式默认只启用 3 条硬约束（教师不冲突、教室不冲突、班级不冲突），以便开箱即用。

### AI 供应商管理

5. 作为**教务管理员**，我希望能添加多个 AI 供应商（DeepSeek、Gemini、自定义中转站），以便选择性价比最高的。
6. 作为**教务管理员**，我希望每个供应商下能添加多个模型，以便不同任务用不同模型。
7. 作为**教务管理员**，我希望能测试供应商连通性，以便确认配置正确。
8. 作为**教务管理员**，我希望能设置"统一模式"（所有 AI 任务用同一模型）或"分开模式"（每个任务独立选模型），以便灵活控制成本。
9. 作为**教务管理员**，我希望模型的高级参数（temperature 等）默认收起，展开后才可修改，以便不被技术细节困扰。
10. 作为**教务管理员**，我希望第一个接入的供应商自动成为默认，以便开箱即用。

### AI 数据导入

11. 作为**教务管理员**，我希望能上传 Excel 文件让 AI 自动解析并录入教师名单，以便不用手工逐条录入。
12. 作为**教务管理员**，我希望能粘贴一段文本（如"张老师教语文，李老师教数学..."）让 AI 解析，以便从微信聊天记录直接导入。
13. 作为**教务管理员**，我希望能上传课表照片让 AI 识别，以便快速录入纸质表格。
14. 作为**教务管理员**，我希望 AI 解析后给我预览表格（系统字段格式），以便确认无误后再入库。
15. 作为**教务管理员**，我希望 AI 标注低置信度的单元格（浅黄底色），以便我重点检查。
16. 作为**教务管理员**，我希望 AI 解释它的映射逻辑（"原始'姓名'列 → 系统 name 字段"），以便我理解它干了什么。
17. 作为**教务管理员**，我希望能手动微调预览表格，然后让 AI 继续解析剩余部分，以便人机接力完成。
18. 作为**教务管理员**，我希望能查看 AI 导入历史（谁、何时、上传了什么、AI 解析结果、最终入库数据），以便审计追溯。

### AI 调代推荐

19. 作为**教务管理员**，我希望在审批调代申请时能点击"AI 推荐代课人"，以便快速找到合适人选。
20. 作为**教务管理员**，我希望 AI 推荐 3 个候选人并说明理由（"李老师同学科、当天该时段无课、本学期代课次数最少"），以便我做决策。
21. 作为**教务管理员**，我希望不点击按钮时 AI 完全不参与，以便保持控制权。
22. 作为**教务管理员**，我希望未配置 AI 供应商时按钮禁用并提示，以便我知道为什么不能用。

## Implementation Decisions

### 初中/高中模式

- 系统设置新增 `school.type` 枚举（`junior` / `senior`），默认 `junior`
- 前端通过 `v-if="schoolType === 'senior'"` 控制组件显示
- 初中模式默认隐藏：约束权重滑块、多草稿对比、约束模板、全校大平铺、教室类型细分、钉钉同步策略
- 初中模式默认启用约束：教师不冲突、教室不冲突、班级不冲突（3 条硬约束）

### AI 供应商管理

- `ai_provider` 表：id、名称、类型（preset / custom）、base_url、api_key（AES-256 加密）、启用状态
- `ai_model` 表：id、provider_id、模型名、显示名、vision_capable、启用状态、参数 JSON
- `ai_task_config` 表：任务类型、分配模式（unified / custom）、provider_id、model_id
- 预设供应商：DeepSeek、Gemini、通义千问、智谱 GLM
- 自定义供应商：OpenAI 兼容端点（含中转站）
- 连接测试：调用 `GET /models` 或轻量 chat 接口验证

### AI 数据导入管道

```
输入通道：
  Excel/CSV → Apache POI 解析为中间 JSON
  文本粘贴 → 直接作为 prompt 上下文
  图片 → 视觉模型直接输出结构化 JSON

统一处理：
  中间 JSON → AI（结构化输出）→ 目标格式预览表格
  预览表格：单元格只读，低置信度浅黄底色标注
  AI 说明：映射逻辑解释

用户选择：
  a) 全部接受 → 直接入库
  b) 手动微调 → 单元格可编辑，改完后：
     - "AI 继续" → AI 基于修正后数据重新解析剩余部分
     - "直接入库" → 用户确认的数据直接入库
  c) 打回重析 → AI 重新解析原始文件
```

- `ai_import_log` 表：完整记录每次导入操作
- 低置信度阈值可配置（默认 0.8）
- 入库前数据校验（必填字段、格式、重复检测）

### AI 调代推荐

- 入口：教务审批界面"AI 推荐代课人"按钮
- 触发方式：手动点击，不自动检测
- 输入：请假教师、课程、日期、课节、候选教师过滤条件
- 输出：3 个候选人 + 推荐理由
- 未配置 AI 供应商时按钮禁用并提示

### AI 网关架构

- 统一 `AiGateway` 接口：`chat(messages, options)` / `chatWithVision(messages, images, options)`
- 策略模式：`DeepSeekStrategy` / `GeminiStrategy` / `OpenAiCompatibleStrategy`
- 配置驱动：从 `ai_provider` + `ai_model` 表加载配置，运行时切换
- 降级策略：AI 调用失败时返回明确错误，不阻断业务流程

## Testing Decisions

### 测试接缝

1. **AI 供应商管理 REST API**：CRUD、连接测试、任务分配切换
2. **AI 数据导入管道**：Excel/文本/图片三种输入的解析、预览、微调、入库全流程
3. **AI 调代推荐**：按钮触发、推荐结果、未配置时的禁用状态
4. **初中/高中模式**：UI 显示切换、约束默认值

### 测试数据

- 准备 3 种格式的测试文件：标准 Excel、格式混乱的 Excel、文本粘贴样本、课表照片
- 用 fake AI 供应商（返回固定响应）做单元测试
- 用真实 DeepSeek API 做少量集成测试（手动跑，不进 CI）

## Out of Scope

- 学生/家长端
- 升学向导
- 多学期对比报表
- 代课费/教师课时统计报表
- 教室预约/借用
- 考试排考
- 移动端专属 UI
- 自定义约束 DSL
- 飞书集成
- 多租户 SaaS
- 新高考走班（高中模式下的 UI 与算法）
- AI 排课结果解释（用户明确不需要）
- AI 冲突诊断（系统直接显示冲突原因）
- OCR 服务（视觉模型直接处理图片）

## Further Notes

### 成本

- DeepSeek `deepseek-flash`：视觉输入 $0.003/1M tokens（缓存命中），极便宜
- Gemini：有免费额度，视觉支持需确认具体模型
- 中转站：价格各异，但 OpenAI 兼容格式统一
