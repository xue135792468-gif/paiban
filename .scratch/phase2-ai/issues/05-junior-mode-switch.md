# 05: 初中/高中模式切换

**What to build:** 实现学校类型设置与初中模式 UI 简化：设置中心新增"学校类型"枚举（初中/高中），默认初中；初中模式下隐藏复杂功能（约束权重滑块、多草稿对比、约束模板、全校大平铺、教室类型细分、钉钉同步策略）；约束配置简化为"必须/尽量"两档；默认只启用 3 条硬约束。完成后，初中教务老师登录系统看到简洁界面，只有"必须/尽量"两档约束，没有权重数字，没有多草稿对比按钮。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `system_config` 表新增 `school.type` 配置项（枚举 junior/senior，默认 junior）
- [ ] 设置中心新增"学校类型"选择器（单选按钮：初中 / 高中）
- [ ] 前端全局状态：schoolType 响应式变量，从后端获取
- [ ] 初中模式隐藏以下功能：
  - 约束权重滑块 → 替换为"必须/尽量"两档开关
  - 多草稿对比视图 → 只保留当前草稿
  - 约束模板保存/加载 → 隐藏，使用内置默认模板
  - 全校大平铺视图 → 隐藏，只保留班级/教师/教室视角
  - 教室类型细分 → 简化为"普通教室/专用教室"两类
  - 钉钉同步策略选择 → 隐藏，默认"钉钉为准"
  - 高中特有约束（选科组合、教研组互斥等）→ 隐藏
- [ ] 初中模式默认约束：只启用教师不冲突、教室不冲突、班级不冲突 3 条硬约束
- [ ] 后端不感知学校类型，所有接口对两种模式一致
- [ ] 切换学校类型时给出确认提示："切换后将刷新页面，初中模式将隐藏高级功能"
- [ ] REST Assured 集成测试：设置切换、约束默认值
- [ ] Playwright E2E 测试：初中模式下界面元素隐藏/显示验证
