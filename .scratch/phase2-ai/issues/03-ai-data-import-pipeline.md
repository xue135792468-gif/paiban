# 03: AI 数据导入管道（Excel/文本/图片 → 预览 → 入库）

**What to build:** 实现 AI 数据导入的完整管道：支持 Excel/CSV 上传、文本粘贴、图片上传三种输入；AI 解析为目标格式预览表格（系统字段格式）；预览表格单元格只读、低置信度浅黄标注、AI 说明映射逻辑；用户可全部接受、手动微调（可编辑）、AI 继续接力、打回重析；最终确认入库。完成后，admin 上传一个格式混乱的教师名单 Excel，AI 自动识别"姓名/学科/电话"列，生成预览表格，admin 确认后 23 个教师入库。

**Blocked by:** 02

**Status:** done

- [x] Excel/CSV 上传接口：Apache POI 解析为中间 JSON（表头行 + 数据行）
- [x] 文本粘贴接口：接收纯文本，直接作为 prompt 上下文
- [x] 图片上传接口：接收图片文件，校验模型 vision_capable，调用 chatWithVision
- [x] AI 解析 Prompt 设计：系统 Prompt 定义目标格式（如 Teacher 的字段：name/subject/phone/...），用户 Prompt 提供原始数据
- [x] AI 结构化输出：强制 JSON mode，返回 `{ mappings: [...], rows: [...], confidence: [...] }`
- [x] 预览表格接口：返回目标格式表格（系统字段为列，数据为行，每单元格带 confidence）
- [x] 低置信度标注：confidence < 阈值（默认 0.8）的单元格标记 `lowConfidence: true`
- [x] AI 说明接口：返回自然语言映射逻辑解释
- [x] 用户确认入库接口：接收最终确认的数据，执行业务校验（必填、格式、重复），入库
- [x] 手动微调接口：用户修改单元格后，可选择"AI 继续"（重新解析剩余部分）或"直接入库"
- [x] 打回重析接口：重新调用 AI 解析原始文件
- [x] `ai_import_log` 表：完整记录每次导入（谁、何时、上传文件、AI 解析结果、用户确认内容、最终入库数据）
- [x] 前端：文件上传组件（Excel/图片/文本粘贴三合一）
- [x] 前端：预览表格组件（只读单元格 + 低置信度浅黄底色 + AI 说明侧栏 + 操作按钮）
- [x] 前端：微调模式（单元格可编辑 + "AI 继续"/"直接入库"/"打回重析"按钮）
- [x] REST Assured 集成测试：三种输入通道的完整流程
- [x] 测试数据：标准 Excel、格式混乱 Excel、文本粘贴样本、课表照片（测试内动态生成）
