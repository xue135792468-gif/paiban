# 06: AI 操作历史与审计

**What to build:** 实现 AI 操作历史页面：展示所有 AI 导入与调代推荐的完整记录（谁、何时、上传了什么、AI 解析结果、用户确认内容、最终入库数据、调代推荐结果），支持按时间/操作人/任务类型筛选，支持查看详情。完成后，admin 能打开"AI 操作历史"页面，看到上周张老师上传了一个 Excel 导入了 23 个教师，看到每次调代推荐的 AI 建议与最终结果。

**Blocked by:** 03, 04

**Status:** done

- [x] `ai_import_log` 表扩展：关联用户、导入类型、文件信息、AI 原始响应、用户确认数据、入库结果（票据 03 已一次性建全，无需新迁移）
- [x] `ai_call_log` 表查询接口：支持按时间/用户/任务类型/供应商筛选
- [x] 前端：AI 操作历史页面（表格列表 + 筛选器 + 详情展开）
- [x] 详情视图：展示完整操作流水（上传文件缩略图、AI 解析结果、用户确认内容、入库数据对比）
- [x] 调代推荐记录：展示推荐时的上下文（请假教师、课程、日期）、AI 推荐的 3 个候选人、最终选择结果
- [x] 导出功能：AI 操作历史可导出为 Excel/PDF（审计用）
- [x] 权限控制：只有 admin 能查看 AI 操作历史
- [x] REST Assured 集成测试：历史记录查询、筛选、权限校验
