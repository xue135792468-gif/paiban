# 05: 多条配置模板可完整往返并兼容旧模板

**What to build:** 用户保存包含多教师、多课程与对象例外的模板后，套用能完整恢复；旧单条模板仍可使用。
**Blocked by:** 03, 04
**Status:** ready-for-agent
**Spec:** ../spec.md

- [ ] 模板往返所有条目、类型控制与作用域，不能退回每类型第一条或最后一条。
- [ ] 旧单条模板升级后含义不变；多次套用不累加重复条目。
- [ ] 审查模板文本容量；大量合法条目可保存/读取，越界不能静默截断；迁移保持两数据库与旧模板兼容。
- [ ] 跨学期行政班引用要求重新绑定或明确拒绝；有效全局教师/课程引用保留，不自动猜同名。
- [ ] 界面显示套用结果与失效引用，任何校验错误都不部分替换现有配置。
- [ ] 通过模板公开 REST＋页面操作先写失败测试，覆盖多类型往返、旧模板、重复套用、非法引用和容量。
- [ ] 独立双轴评审、完整闸门与模板页面截图完成。

**范围边界：** 不引入自动跨学期实体合并；沿用既有模板替换语义。
