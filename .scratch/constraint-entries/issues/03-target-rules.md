# 03: 其余目标型约束支持多对象与正确组合

**What to build:** 用户可以给多门课程、多个教师或多个教研时段分别配置条件，各条在对应表单和评估中生效，互不覆盖。
**Blocked by:** 02
**Status:** ready-for-agent
**Spec:** ../spec.md 的全目录表（目标型 13 类，本票补齐其余 12 类）

- [ ] 覆盖教研禁排、课程教室类型、不排晚自习、同课每日一次、体育下午第一节、连堂、课程分散、主科上午、教师偏好、教师首节、无课日、体育末节。
- [ ] 多偏好时段采用“或”；禁排/固定无课日按并集；相同违反事实不因全局/具体目标重叠而重复惩罚。
- [ ] 同课程互斥教室类型、重复条目及不可兼容标量条件明确拒绝，失败不部分写入。
- [ ] 保留“全部课程”“默认体育类”和各类既有计数/参数含义。
- [ ] 每类都可通过相应最小表单完成配置和重新读取；求解、草稿、调代硬/软检查与 CLI 读取同一条目语义。
- [ ] 生成调代方案后修改本票目标型规则，审批按当前硬规则与软评分重验，失败不部分生效。
- [ ] 全目录清单逐类标明测试证据，不能只断言两个 teacherId；先红后绿，独立双轴评审、完整闸门及关键截图。

**范围边界：** 不新增任意 DSL，不改变各规则的原始业务定义；阈值在 04。
