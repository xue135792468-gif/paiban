# 04: 五类阈值支持全局默认和具体对象例外

**What to build:** 用户能设置全校默认上限，同时为个别适用对象设置不同上限；未被覆盖的对象继续使用默认。
**Blocked by:** 02
**Status:** ready-for-agent
**Spec:** ../spec.md

- [ ] 五类分别支持：教师每日/连续上课→教师，班级每日/晚自习→行政班，课程每日→课程；界面只提供适用对象。
- [ ] 全局默认＋对象例外有明确摘要、编辑和删除入口。同类型启用/软硬/权重仍共用。
- [ ] 对象例外替代该对象全局阈值；例外删除恢复全局。无全局值时不对未覆盖对象凭空启用默认规则。
- [ ] 同一对象或全局重复阈值拒绝；上下界和行政班学期校验仍有效，失败原子性不变。
- [ ] 具体例：全局 6、教师甲 3，甲第 4 节触发，乙第 4 节不触发；按原计数桶验证另外四类。
- [ ] 生成调代方案后改变对象例外/全局阈值，审批按当前规则重验；删除例外恢复全局，关闭类型关闭全部条目。
- [ ] 求解、草稿、调代硬检查/软评分与 CLI 使用相同选择策略；先红后绿，独立双轴评审、完整闸门与页面证据。

**顺序说明：** 与 03 共享基础但无硬依赖；用户可按 03→04 顺序集成，避免并行改同一规则模块。
