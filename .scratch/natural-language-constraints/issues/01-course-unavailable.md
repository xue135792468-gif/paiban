# 01: 手动配置课程禁排，打通分组要求与逐项控制

**What to build:** 教务可以选择体育、每个上课日或指定星期、多个连续或不连续课节，保存后整体修改、暂停或删除这项要求。课程禁排在排课、草稿/发布及调代中生效；首次带出兼容的要求分组和逐项控制，其他既有类型继续正常使用。

**Blocked by:** None (can start immediately).

**Status:** done（2026-10-27）

2026-10-27 用户已确认本轮12票拆分及阻塞关系，正式发布；实现范围与共同约束以[正式规格](../spec.md)为准。

- [ ] 新增课程禁排类型及手动表单，支持“体育每天上午第1、2节”和“化学周三、周五上午第1节及下午第2节”。按当前学期实际作息定位，不能把下午第2节当全天第2节，也不能扩成连续区间。
- [ ] 一项要求保存稳定身份和多个具体课节，同组整体编辑、暂停、删除；不同强度可以是不同要求，不能只按课程名称重新拼成一组。课程禁排不影响同一教师的其他课程。
- [ ] 本类型支持逐项启停、必须/尽量、软重要程度，未覆盖值继承类型默认；总开关关闭再打开保留逐项状态，硬要求不显示软权重。组内课节控制一致。
- [ ] 共同契约先兼容扩展：存储、完整配置读写与页面可无损表达身份、分组和覆盖。旧数据/旧请求适配后含义不变，未迁移类型仍使用旧类型控制且不开放未实现的逐项设置；无法无损表示新配置的旧请求明确拒绝。
- [ ] 模板的最小无损扩展随本票完成：新课程要求的分组和控制经保存、预览、套用后保留，不能清空覆盖值或只剩参数。既有模板继续可读，不把模板兼容拖到后续才补。
- [ ] 同一课程禁排限制的相同违反事实只计一次：硬/软重叠按硬，全软取较高重要程度。不同限制仍各自评估；相同条件不同控制是可确认的变化或重叠，不能沿用旧参数去重误拒合法组合。
- [ ] 本类型的求解、草稿/发布、调代硬检查/软评分与只读校验全部同步，保留调代差分审批语义；不能仅修改共享设置却漏掉直接按类型判断的调用方。
- [ ] 添加/回读/保存复核课程和作息，失效或改义课节定位到要求、等待重选；“每日/上午”按确认时展开，后来新增课节不自动扩大，相关变化提示复核。
- [ ] 迁移保留既有数据含义，实施时核对可用编号；后端定向集成验证真实保存回读、模板及各评估入口，Playwright完成手动多选、保存重开、独立控制与暂停截图。其余旧目录回归保持绿。

验收映射：C18/C21/C22的手动等价场景；A03/A04/A05/A13/A17的新增类型部分。此票是共同契约的兼容扩展及第一条纵向路径，不承担一次迁完全部旧类型。
