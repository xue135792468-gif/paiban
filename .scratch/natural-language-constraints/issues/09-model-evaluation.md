# 09: 用22句语料评测候选模型，在20元内报告可用性

**What to build:** 管理员可以按固定学校语料评测现有可用模型，查看逐次结果、失败、耗时和费用，依据明确标准选择自然语言约束任务使用的模型；没达标就如实报告，不凭演示或名称判断。

**Blocked by:** 08 — 在约束页生成只读建议，保留原话与原始结果。

**Status:** ready-for-agent

2026-10-27 用户已确认本轮12票拆分及阻塞关系，正式发布；实现范围与共同约束以[正式规格](../spec.md)为准。

- [ ] 提供可重复执行的评测入口和报告，使用真实的生成/规范化公共边界与固定合成上下文；先记录供应商、模型、参数、目录/默认值和语料版本，再对C01–C22各运行3次。
- [ ] 明确支持的C01–C15、C18、C21、C22共54次，至少52次整句语义完全正确；类型、对象、范围、数量、星期/课节和必须/尽量均正确才计对，不按字段拆分凑分。
- [ ] C16/C17/C19/C20共12次单独要求零误转，不混入95%分母；C16保留明确体育项同时对同名教师待选择。全部拒绝、模型乱猜被后置校验挡住或格式合法均不能冒充正确理解。
- [ ] 先测一个现有可用模型，未过才最多比较第二个；每模型66次，费用限制可使其提前停止，不为凑次数超支。失败、超时及未达标输出均完整报告。
- [ ] 本轮真实评测总费用上限20元人民币；调用前可靠核实单价、上下文/输出上界与换算口径，逐次预留下一次最坏费用，所有已发出且可能计费的请求均纳入。价格不可靠、余额不足或预算用完立即停，不自动加模型/重试/降门槛。
- [ ] 预算守卫用本地供应商stub验证会拦住超预算下一次调用；真实评测独立人工触发，CI不访问真实模型、不计入固定集正确率。
- [ ] 报告区分原始输出、服务器校验与规范化建议，逐句给通过/失败及原因，计算清晰。达到固定集门槛只证明该范围，未过则报告未达标，不以“模型绑定完成”替代可用性证据。
- [ ] 记录实际消费和剩余额度，按评测结果给出任务绑定建议或在现有设置中完成明确绑定；仍保持AI默认关闭，不把20元解释为生产日额度。不需要等待确认加入、跨设备工作区或完整页面收口。
