# 08: 在约束页生成只读建议，保留原话与原始结果

**What to build:** 有约束管理权限的用户可以在约束页输入要求，看到按独立要求分组的结构化建议、歧义或不支持原因，并查看本人的生成记录；生成不写生效配置，取消和60秒超时有明确边界。

**Blocked by:** 01 — 手动配置课程禁排，打通分组要求与逐项控制。

**Status:** ready-for-agent

2026-10-27 用户已确认本轮12票拆分及阻塞关系，正式发布；实现范围与共同约束以[正式规格](../spec.md)为准。

- [ ] 新增独立自然语言约束任务槽，沿用现有供应商/模型管理与统一网关；默认关闭，未开启/模型未配时约束页保留入口和原因，不发请求，手动配置可用。不硬编码供应商或固定模型。
- [ ] 最小可用页面完成输入、生成及分组查看，显示原话、类型、对象、条件、必须/尽量、解释与状态；此阶段只读，不允许绕过后续确认票直接保存。
- [ ] 支持现有24类加课程禁排的规范化建议契约，与共同要求模型一致；服务器校验目录、对象、学期作息和参数，保留明确项，其他区分待补齐/未转换/非法。不猜同名、不猜数量、不扩大范围，也不以全部拒绝规避正常转换。
- [ ] 明确禁令按必须、尽量/优先/最好按尽量，按完整句子处理修饰关系；无强度用类型默认并显示，不随意生成重要程度数值。上午/下午/相对课节依据学期作息解释。
- [ ] 每个用户触发建立稳定轮次/运行身份，一次最多60秒且不自动重试；同轮重放不能重复发送模型请求，不改变其他AI任务的既有策略。
- [ ] 取消或超时保留原话，晚响应只进记录、不回填或污染新轮次；模型请求在事务外，失败返回结构化结果并审计，保留用户主动重试入口。
- [ ] 请求只包含理解所需原话、相关对象名称、作息及目录，不含手机号等无关信息；凭据掩码。原始模型输出、规范化建议及失败/取消分别记录，不能用截断通用日志假冒完整业务记录。
- [ ] 业务用户可通过页面和公开接口重开本人的生成记录，管理权限可查全局；服务端阻止越权读他人记录。原始输出不会被之后人工结果覆盖。
- [ ] CI使用本地HTTP stub或固定响应，覆盖C01–C22的确定性解析/护栏、任务配置、结构化失败、60秒、无重试、重复触发与晚响应；Playwright完成输入、查看、取消、记录和不可用状态并截图。本票不花20元调用真实模型。

验收映射：C01–C22的只读生成/规范化边界；A09/A11/A12/A14/A16/A18的生成部分。只读建议与真实语料评测不依赖所有旧类型已迁移到可保存的新控制。
