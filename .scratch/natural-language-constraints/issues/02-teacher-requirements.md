# 02: 教师与教研要求各自设置必须或尽量

**What to build:** 教务能让王老师周三下午必须不排、李老师周五下午尽量不排，分别暂停和调重要程度；同一教师多个偏好时段仍是可选集合。教研禁排在初中模式也可找到并修改。

**Blocked by:** 01 — 手动配置课程禁排，打通分组要求与逐项控制。

**Status:** ready-for-agent

2026-10-27 用户已确认本轮12票拆分及阻塞关系，正式发布；实现范围与共同约束以[正式规格](../spec.md)为准。

- [ ] 覆盖教师禁排时段、教研活动禁排、教师偏好时段、教师不排第一节、教师固定无课日共5类。手动新增、编辑、保存回读保留真实要求分组和身份，不按教师强行合并独立要求。
- [ ] 每类支持逐项启停、必须/尽量及软重要程度的继承/覆盖；修改一项不改变其他显式设置。类型总开关重开保留逐项状态，多课节要求整体管理。
- [ ] 同一禁排限制同一事实重叠时硬优先、全软取较高重要程度，不重复扣分；不同对象/不同限制分别处理，教师和教研的作用对象仍依原义。
- [ ] 同一教师全部有效偏好时段按可选集合：硬偏好A、软偏好B，命中任一即满足；均未命中才按硬优先计一次违反。全软取较高重要程度，不能逐条重复奖励或扣分。
- [ ] 初中模式开放教研禁排并用易懂说明，两种模式可按需展开软重要程度。其他学校模式裁剪不擅自扩张。
- [ ] 旧配置升级后实际含义不变，模板往返保留本族分组与覆盖；空列表仍未配置，全部学科必须显式表达。非法对象/课节和完全重复要求不静默落库。
- [ ] 同步本族求解、草稿/发布、调代硬检查/软评分及只读校验；覆盖配置收紧后调代审批按当前规则重验且保持差分口径。
- [ ] 定向后端持久化及规则测试验证两教师不同强度、偏好可选集合、关闭/恢复及模板；Playwright演示教师与教研配置并截图，不以只测页面控件代替实际生效。

验收映射：C01/C02/C03/C15的手动等价场景；A02/A03/A04/A13/A18的本族部分。
