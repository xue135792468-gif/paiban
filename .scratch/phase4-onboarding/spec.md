# 排课系统四期规格：操作引导与帮助中心

Status: done（已上线）

---

## Problem Statement

一期二期三期交付后，系统功能已完整（排课、调代、AI 辅助、双平台集成）。但新用户（教务老师）上手成本高，面对复杂界面不知道从何开始。需要一套操作引导与帮助体系，降低学习门槛。

## Solution

四期实现完整的操作引导与帮助中心：

1. **新手教程（Tour）**：首次登录时高亮关键区域，一步步介绍核心功能
2. **空状态引导**：页面无数据时显示引导图文与操作按钮
3. **上下文提示（Tooltip）**：鼠标悬停时显示功能说明
4. **帮助文档中心**：纯文字/图文教程，按功能模块与场景流程组织，支持快速跳转

## User Stories

### 新手教程（Tour）

1. 作为**新教务管理员**，我希望首次登录时系统能引导我了解界面布局，以便快速上手。
2. 作为**新教务管理员**，我希望能跳过新手教程，以便我不需要时可以直接开始工作。
3. 作为**教务管理员**，我希望能在设置里重新打开新手教程，以便我忘记时可以重新学习。
4. 作为**教务管理员**，我希望新手教程只显示一次，以便不重复打扰我。

### 空状态引导

5. 作为**教务管理员**，我希望在"班级管理"页面没有数据时，看到"还没有班级数据"的提示和【立即创建】按钮，以便我知道该做什么。
6. 作为**教务管理员**，我希望空状态提示里有"查看帮助文档"链接，以便我可以深入了解。
7. 作为**教务管理员**，我希望空状态引导覆盖所有核心页面（班级、教师、教室、课程、授课任务、约束、排课），以便我不至于迷路。

### 上下文提示（Tooltip）

8. 作为**教务管理员**，我希望鼠标悬停在"约束权重"上时显示"0-100 表示优先级，越高越优先满足"，以便我理解这个字段的含义。
9. 作为**教务管理员**，我希望所有复杂字段都有 Tooltip 提示，以便我不需要猜。

### 帮助文档中心

10. 作为**教务管理员**，我希望有一个帮助文档中心，按功能模块（基础数据、排课、调代、课表查看、设置）组织，以便我查找特定功能的使用方法。
11. 作为**教务管理员**，我希望帮助文档里有场景流程（新学期开学流程、日常调代流程、期末统计流程），以便我按步骤完成工作。
12. 作为**教务管理员**，我希望帮助文档里的"点击这里创建班级"能直接跳转到对应页面，以便我不需要手动找菜单。
13. 作为**教务管理员**，我希望帮助文档是纯文字/图文形式，以便加载快、打印方便。

## Implementation Decisions

### 新手教程（Tour）

- 使用 driver.js 实现，轻量（<10KB）、Vue 3 兼容
- 触发时机：首次登录可选跳过，设置里可重开
- 覆盖页面：基础数据页、排课页、调代页
- 持久化：localStorage 记录"已看过"，分阶段显示（基础 → 高级）

### 空状态引导

- 每个列表页/详情页的无数据状态显示：提示文字 + 操作按钮 + 帮助链接
- 统一组件：`EmptyStateGuide`，接收 props（标题、描述、按钮文字、按钮动作、帮助链接）

### 上下文提示（Tooltip）

- 使用 Element Plus 的 `el-tooltip` 组件
- 所有复杂字段添加 `tooltip` 属性，内容从配置读取

### 帮助文档中心

- 前端路由 `/help`，静态 Markdown 文件渲染
- 结构：功能模块为主（基础数据/排课/调代/课表/设置），场景流程为辅（开学/调代/期末）
- 快速跳转：Markdown 中的链接直接路由到对应页面（如 `/foundation/classes`）
- 纯文字/图文，无视频

## Testing Decisions

### 测试接缝

1. **新手教程**：Playwright 验证首次登录弹出、跳过、重开
2. **空状态引导**：Playwright 验证无数据时显示引导、按钮跳转
3. **帮助文档**：Playwright 验证路由、Markdown 渲染、快速跳转
4. **上下文提示**：单元测试验证 Tooltip 内容正确

## Out of Scope

- 视频教程
- 智能助手（Chat）
- 数据报表与统计
- 新高考走班
- 考试排考
- 教室预约/借用

### 内容规划

帮助文档需要撰写以下内容：

- 功能模块：基础数据（年级/班级/教师/教室/课程）、排课（约束/提交/草稿/发布）、调代（申请/审批/查看）、课表查看（视角切换/导出）、设置（学校类型/AI/集成）
