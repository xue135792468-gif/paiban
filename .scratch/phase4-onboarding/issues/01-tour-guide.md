# 01: 新手教程（Tour）

**What to build:** 实现首次登录的新手教程：使用 driver.js 高亮关键区域，一步步介绍核心功能（基础数据、排课、调代）。首次登录可选跳过，设置里可重开，只显示一次。完成后，新教务管理员第一次登录看到"欢迎使用排课系统"的引导，依次介绍"这里是班级管理""这里可以提交排课""这里处理调代申请"。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 引入 driver.js 依赖（<10KB，Vue 3 兼容）
- [x] 新手教程组件：封装 driver.js，支持步骤定义、跳过、完成回调
- [x] 首次登录检测：localStorage 标记 `hasSeenTour`，首次登录时弹出教程
- [x] 教程步骤定义：
  - 步骤 1：欢迎页（系统简介）
  - 步骤 2：基础数据管理入口（年级/班级/教师/教室/课程）
  - 步骤 3：排课入口（约束配置/提交排课）
  - 步骤 4：调代入口（申请/审批）
  - 步骤 5：课表查看入口（四视角切换）
  - 步骤 6：完成页（"开始使用的"按钮）
- [x] 跳过功能：每步显示"跳过教程"按钮
- [x] 重开功能：设置页添加"重新查看新手教程"按钮
- [x] 分阶段显示：基础教程（首次）→ 高级教程（使用排课功能后触发）
- [x] Playwright E2E 测试：首次登录弹出、跳过、重开、步骤切换
