# 发布交接边界

本批已于2026-11-02按用户后续明确授权合并main并部署生产。应用版本d76709c，备份、镜像、健康和数据保护证据见[deployment.md](deployment.md)。以下保护与回退边界继续适用。

数据库结构没有变化，未新增Flyway迁移，仓库最高版本仍为V44。新增规则复用constraint_config、constraint_entry的既有条目/分组/版本/审计机制。旧规则默认保持；没有每周不上课配置的学期不会自动增加留空要求。

正式发布需沿用[部署跑册](../../docs/runbooks/deploy.md)：选定实际验证过的源码版本，保存数据库备份与原应用镜像，核对迁移/容器健康和业务冒烟。本机无Docker，真实PostgreSQL校验由最终同提交GitHub CI的backend日志核对；H2验证不能替代它。

本批没有DDL变更，应用代码可以回退到原版本；旧版应用不执行新增禁排规则，回退后教务必须知晓该行为；正式发布仍必须保留备份。新增规则可能让现有草稿出现冲突或剩余位置不足，这是应提示教务修正规则/任务的业务结果，不能通过删课或改正式基线掩盖。原始已发布课表保留，后续调课受当前规则约束。

自然语言生成新类型尚未开放，继续手动配置；具体日期临时停课/补课不在此批范围。不得把容量足够说成已证明能排完所有教师/教室/组合约束。
