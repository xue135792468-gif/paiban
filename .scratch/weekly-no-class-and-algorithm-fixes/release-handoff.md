# 发布交接边界

本批实现与验收在`codex/weekly-no-class`集成分支。本轮没有部署、合并main或更改生产数据，生产当前运行版本未在本轮复验。代码与最终门禁结论以06验收记录为准；当前仍在集中修复后的复审阶段。

数据库结构没有变化，未新增Flyway迁移，仓库最高版本仍为V44。新增规则复用constraint_config、constraint_entry的既有条目/分组/版本/审计机制。旧规则默认保持；没有每周不上课配置的学期不会自动增加留空要求。

正式发布需沿用[部署跑册](../../docs/runbooks/deploy.md)：选定实际验证过的源码版本，保存数据库备份与原应用镜像，核对迁移/容器健康和业务冒烟。当前本机无Docker，真实PostgreSQL校验拟由同版本GitHub CI提供；H2验证不能替代它。

本批没有DDL变更，应用代码可以回退到原版本；正式发布仍必须保留备份。新增规则可能让现有草稿出现冲突或剩余位置不足，这是应提示教务修正规则/任务的业务结果，不能通过删课或改正式基线掩盖。原始已发布课表保留，后续调课受当前规则约束。

自然语言生成新类型尚未开放，继续手动配置；具体日期临时停课/补课不在此批范围。不得把容量足够说成已证明能排完所有教师/教室/组合约束。
