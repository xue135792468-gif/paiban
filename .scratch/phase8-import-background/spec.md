# 排课系统八期规格：导入后台任务与部分结果

Status: draft（七期完成后再拆票）

---

## Problem Statement

课表分批解析是同步请求：14 个班约 6.5 分钟，浏览器要一直等；任何一批失败，整个导入标记失败，前面成功的批次不展示；没有停止、重试失败批次或放弃的入口。

## Solution

1. **后台任务 + 轮询**：上传立即返回会话 ID，后台一批一批处理，每批落盘；前端每 2 秒查一次会话；新增 `PARSING` 状态与停止接口。
2. **部分结果**：某批失败时保留已成功批次，状态 `PARTIAL`，展示已解析的班与失败班列表。
3. **重试失败批次**：只重跑失败的班，合并去重。
4. **停止解析 / 放弃导入**：停止保留已有结果；放弃标记 `ABANDONED`，不生成草稿、不写业务数据。
5. **不默认部分入库**：缺班的草稿可能被误发布；默认只提供重试或放弃。

## Out of Scope

- 视觉/图片导入。
- 部分入库（缺班草稿）。
- 按班并发解析（先保持串行，避免中转 429）。

七期已落地会话恢复与年级推断；八期只处理「解析过程本身」的健壮性与进度。具体接口、状态机与票在七期合并后拆。
