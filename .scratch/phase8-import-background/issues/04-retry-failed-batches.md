# 04: 重试失败批次

**What to build:** `PARTIAL` 会话可以只重跑失败批次，已经成功的批次不会再次调用 AI。重试成功后与已有批次合并去重，全部成功则回到 `PREVIEW`；仍然失败则保持 `PARTIAL` 并更新失败列表与原因。

**Blocked by:** 03

**Status:** done

- [x] 重试只对失败批次发起 AI 调用（用调用次数断言）
- [x] 成功重试后合并去重，行数与批次统计正确，状态回到 `PREVIEW`
- [x] 再次失败仍为 `PARTIAL`，失败列表与原因更新
- [x] 前端提供重试入口并反馈本次重试结果
- [x] 测试覆盖「重试成功」「重试仍失败」「不重复调用成功批次」

**实现说明：** `POST /sessions/{id}/retry` 返回 `PARSING` 的会话，前端沿用轮询；`total_batches` 保持原计划数，`completed` 是已成功批数，`failed` 是本轮待重试批数。重试批次读 `batches_json` 里的 `sourceRows`，源文件被清理后仍可重试（表头上下文会降级）。每轮的停止标记按轮次隔离，旧轮次在飞批次写不回新一轮。
