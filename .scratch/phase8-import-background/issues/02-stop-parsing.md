# 02: 停止解析

**What to build:** 解析过程中提供「停止解析」。停止后不再发起新的 AI 调用，已完成批次保留，会话回到可继续处理的状态（`PREVIEW`），用户可以继续映射、入库，或重新解析。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 停止接口只在 `PARSING` 下可用；其他状态返回明确的冲突错误
- [ ] 停止后不再发起新的 AI 调用，已完成批次的数据保留
- [ ] 前端在解析中显示停止入口，停止后给出可读提示并进入预览
- [ ] 停止后的预览可以正常映射与确认入库
- [ ] 测试覆盖「停止后保留结果」与「重复停止被拒绝」
