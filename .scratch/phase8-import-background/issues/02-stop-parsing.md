# 02: 停止解析

**What to build:** 解析过程中提供「停止解析」。停止后不再发起新的 AI 调用，已完成批次保留，会话回到可继续处理的状态（`PREVIEW`），用户可以继续映射、入库，或重新解析。

**Blocked by:** 01

**Status:** done

- [x] 停止接口只在 `PARSING` 下可用；其他状态返回明确的冲突错误
- [x] 停止后不再发起新的 AI 调用，已完成批次的数据保留
- [x] 前端在解析中显示停止入口，停止后给出可读提示并进入预览
- [x] 停止后的预览可以正常映射与确认入库
- [x] 测试覆盖「停止后保留结果」与「重复停止被拒绝」

**实现说明（与票面的两处偏差，均为安全性收紧）：**
1. 停止时若已有失败批次，会话收尾为 `PARTIAL` 而不是 `PREVIEW`——避免把缺班的预览当成完整结果导入（与 03 票一致）。
2. 第一批都还没完成就停止时收尾为 `FAILED`（说明「已停止解析，没有任何已完成的批次」），不再给出 0 行、可点入库的空预览。
其余情况（有已完成批、无失败批）仍按票面回到 `PREVIEW`，可正常映射与入库。停止会丢弃尚未开始解析的批次，预览说明里写明「剩余 N 批未解析」；需要整表重来时用【打回重析】，大表会重新走分批解析。
