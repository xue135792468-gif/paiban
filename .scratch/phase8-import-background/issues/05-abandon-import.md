# 05: 放弃导入（ABANDONED）

**What to build:** 解析中或 `PARTIAL` 状态下可以「放弃导入」，会话标记为 `ABANDONED`：不生成草稿，不写入任何业务数据，会话记录保留用于审计。放弃后的会话不再作为可继续的导入出现在恢复入口。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 解析中与 `PARTIAL` 下都可以放弃，状态变为 `ABANDONED`
- [ ] 放弃不创建草稿、授课任务、班级等业务数据（用查询断言）
- [ ] 会话记录保留，可在导入历史中查看状态与原因
- [ ] 「上次导入」与 URL 恢复入口不再把 `ABANDONED` 当作可继续会话
- [ ] 测试覆盖两种放弃入口与「无业务数据写入」
