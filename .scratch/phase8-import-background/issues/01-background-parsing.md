# 01: 后台解析与进度轮询

**What to build:** 上传大课表后立即返回导入会话，解析转到后台逐批进行；解析期间会话处于 `PARSING`，每批结果即时落盘；前端每 2 秒刷新一次进度（已完成/总批次、当前批次），全部完成后自动进入预览，可以继续映射与入库。数据行不超过 3 行的课表仍走原有的一次性路径，体验不变。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 上传大课表立即返回会话，不再等待整次解析完成
- [x] 导入会话新增 `PARSING` 状态与进度（已完成批次数、总批次、当前批次标签）
- [x] 每批解析成功后立即落盘，进程中断不丢已完成批次
- [x] 前端解析页显示进度，完成后自动进入预览
- [x] 小于等于 3 个数据行的课表仍一次返回预览
- [x] 集成测试覆盖后台解析、进度查询与最终预览；E2E 覆盖大表后台解析

**实现说明：** 批次落盘在 `ai_import_log` 新增的 `batches_json` / `total_batches` / `completed_batches` / `current_batch`（迁移 V20）；后台执行用独立的 `importExecutor`（单线程，不复用求解器线程池）。进度除票据要求的三项外增加 `failed`，供 03/04 票复用。进程重启时残留 `PARSING` 会话按已完成批收尾（有完成批 → `PARTIAL`/`PREVIEW`，无完成批 → `FAILED`），不会把中断的会话伪装成完整预览。
