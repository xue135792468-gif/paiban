# 票据 06: warm start 的完整草稿要排除班级/教师冲突

Status: ready-for-agent
Category: bug
Priority: P2
**Spec:** ../spec.md
**来源:** 2026-10-31 code-review Spec 残余项（拆分自原票 06）

## What

warm start 的「完整草稿」目前只检查：行非空、每个课节有作息时段、每个 assignment 的周课时数备齐。它不检查草稿内部是否有重复时段：如果一份旧草稿把同一班的两节课排在同一时段，或同一老师在同一时段有两节课，它仍会被选为 warm start，求解器从一个带硬冲突的解起步。

## Why

用户要求「自动排课必须能直接发布」。有基线/导入草稿的路径已满足；但如果 warm start 选到一份带班级/教师冲突的「完整」草稿，就直接违背这个目标。需要在选草稿时排除它，继续找下一份。

## Acceptance

- [ ] `isComplete` 增加冲突校验：同一 `(班级, 时段)` 与同一 `(教师, 时段)` 各只能出现一次；有重复则跳过该草稿，继续找下一份。
- [ ] 增加一份带重复时段的草稿测试，证明它不会被选中。
- [ ] 补一个「部分草稿（课时未备齐）被跳过」的单元测试，证明 `isComplete` 因覆盖校验不通过而不会选中该草稿。
- [ ] 不改变 warm start 的来源优先级，不改变固定教室/评分逻辑。

### Agent Brief

**Category:** bug
**Summary:** A "complete" warm-start draft must also have no class or teacher double-booking before it is selected.

**Current behavior:**
A draft is considered complete when it has rows, every lesson has a period, and each assignment's weekly lesson count is covered. Duplicate `(class, period)` or `(teacher, period)` rows are not checked, so a conflicting draft can seed the solver.

**Desired behavior:**
When evaluating candidate drafts for warm start, a draft with any duplicate `(class, period)` or `(teacher, period)` is skipped; the next candidate is considered. If none qualifies, no warm start is used. The source priority stays: published baseline, then the oldest complete draft, then none.

**Key interfaces:**
- The draft-completeness decision (currently inside the warm-start seeding logic) gains the two uniqueness checks.
- The checks operate on the same `(class, course, teacher, period)` rows the seeding logic already reads.

**Acceptance criteria:**
- [ ] A draft with two lessons of the same class in one period is not selected.
- [ ] A draft with two lessons of the same teacher in one period is not selected.
- [ ] A draft missing weekly lessons is still skipped (existing coverage behavior).
- [ ] A valid complete draft is still selected and seeds the same periods as before.
- [ ] Unit tests cover the three rejected shapes and the accepted shape.

**Out of scope:**
- The blank-semester UI warning and guarantee wording (ticket 07).
- Re-validating drafts with the full constraint catalogue; only class/teacher period uniqueness is in scope.
- Changing warm-start source priority or fixed-room logic.
