# 01: 钉钉通讯录递归同步

**What to build:** 教务管理员点一次「同步通讯录」，系统递归遍历钉钉部门树，把应用权限内能读到的全部教职工导入本地教师表，而不是只导入根部门直属的 2 个人。负 id 部门（含 `-7` 家校通讯录）跳过；同一用户跨部门只导入一次；离职人员导入为停用；成功日志写明扫描了多少部门、多少人、耗时多久。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 从根部门递归 `department/listsub`，深度优先遍历整棵部门树；部门 id 为负数的直接跳过，不报错
- [ ] 每个部门用 `user/list` 分页拉取到底，跨部门按 `userid` 去重
- [ ] 不引入部门白名单或 `sync-dept-id` 设置项；导入范围完全由钉钉权限决定
- [ ] 部门名含「离职」或用户 `active=false` 的用户落库为 `active=false`，不出现在排课候选
- [ ] 同一用户出现在多个部门时只创建/更新一次
- [ ] 成功路径输出 INFO：扫描部门数、用户数、耗时；`OrgSyncResult` 带扫描量
- [ ] 钉钉错误透传 `errcode` / `sub_code`；IP 白名单错误（88/60020）给出明确提示
- [ ] 假客户端单元测试覆盖：三级部门树、重复用户、负 id 部门、离职部门、分页边界、`errcode=41`
- [ ] 云端实测：扫描部门数与用户数与钉钉后台可见范围一致；47 位存量教师不被重复创建
